# 무협 게임 — 성격 · 체질 · 숨겨진 특성 · 유산 · 벽 · 사망 정산

> `wuxia-game.md` 4장(캐릭터 생성) · 7장(경지와 벽) · 8장(사망 정산) · 9장(전생 유산)에서 비어 있던 **목록과 화면**을 채운다.
> 원칙: 화면엔 한 줄, 속은 깊게. 좋고 나쁨이 고정된 것보다 **상황 따라 득실이 갈리는 것**을 우선.

## 1. 성격 (빙의할 때 1개 랜덤 · 바뀌지 않음)

성격은 **① 부재 중 기본 반응**(`1강호 성향`을 안 정했을 때) **② 사건 가중치** **③ NPC 첫인상** 에 쓰인다. 플레이어가 성격과 다르게 행동해도 막지 않는다 — 다만 성격대로 하면 작은 덤(깨달음 · 호감)이 붙는다.

| 성격 | 부재 중 기본 | 사건 · 판정 | NPC 반응 |
|---|---|---|---|
| 대담 | 맞선다 | 위험 사건↑ · 위협 판정↑ | 무인 호감↑ |
| 신중 | 도망친다 | 함정 · 기습 알아챔↑ | 상인 · 원로 호감↑ |
| 겁이 많음 | 도망친다(신법↑) | 도망 판정↑ · 싸움 사건↓ | 얕보임 |
| 다혈질 | 맞선다 | 시비 사건↑ · 첫 합 기세↑ | 사파 호감↑ · 정파 경계 |
| 냉정 | 맞선다(불리하면 도망) | 주화입마 위험↓ | 살수 · 제갈 호감↑ |
| 의협심 | 맞선다(약자 편) | 구조 · 의로운 사건↑ | 민심↑ · 개방 호감↑ |
| 탐욕 | 돈을 준다/받는다 | 돈 · 보물 사건↑ · 사기 당함↑ | 상인 경계 |
| 호기심 | 거래 수락 | 동굴 · 기연 사건↑ · 함정↑ | 기인 호감↑ |
| 의심 많음 | 거래 거절 | 사기 · 위본 알아챔↑ · 인연↓ | 정보상 호감↑ |
| 낙천 | 항복(살아남기) | 부상 회복↑ · 깨달음 조금↑ | 대체로 호감 |
| 음험 | 돈을 준다(뒤통수 노림) | 암습 · 독 사건↑ | 정파 경계 · 혈교 · 살수 호감 |
| 고지식 | 맞선다 | 약속 · 문파 사건↑ · 거짓말 판정↓ | 소림 · 무당 호감↑ |
| 자유분방 | 도망친다 | 떠도는 사건↑ · 문파 규율 사건에서 마찰 | 녹림 · 수적 호감↑ |
| 다정 | 거래 수락 | 인연 · 혼인 사건↑ | 마을 · 아이 호감↑ |
| 오만 | 맞선다 | 도전 사건↑ · 원한↑ | 세가 호감↑ · 하층 경계 |
| 무심 | 항복 | 사건 영향 덜 받음(호감 변화 작음) | 기인 · 고승 호감↑ |

## 2. 체질 (빙의할 때 0~1개 · 영약 · 사건으로 생기거나 바뀜)

| 체질 | 효과 | 대가 |
|---|---|---|
| 독에 강함 | 독 상태 짧음 · 독공 적성 | 해독약 효과도 약함 |
| 한빙지체 | 얼음 기운 무공↑ · 북방 설원에 강함 | 불 · 열 사건에 약함 |
| 화령지체 | 열 기운 무공↑ · 상처 회복↑ | 주화입마 시 피해↑ |
| 천생신력 | 중(重) 무공↑ · 무기 파손 덜 함 | 신법 성장↓ |
| 경골 | 신법↑ · 도망↑ | 맞으면 부상 단계 한 칸 더 |
| 철골 | 부상 단계 한 칸 덜 | 신법↓ |
| 맑은 눈 | 기운 · 역용 · 위본 알아봄 | 귀물 · 요괴에게 잘 보임 |
| 요기에 민감 | 요괴 · 요수 기척을 먼저 앎 | 요기 사건↑(좋든 나쁘든) |
| 약골 | 수련 효율↓ · 병치레 | 의술 · 심법 깨달음↑(아픈 만큼 안다) |

| 음양 불균형 | 마 · 혈 기운 성장↑ | 정 · 불 기운 주화입마↑ |
| 장수 체질 | 최대 수명 +15 | 성장 조금↓ |
| 피 냄새 | 요수 · 혈교가 잘 찾아냄 | 혈 기운 무공↑ |

## 3. 숨겨진 특성 (빙의할 때 0~1개 · **본인도 모름** · 조건이 맞으면 드러남)

| 숨겨진 특성 | 드러나는 조건 | 드러나면 |
|---|---|---|
| 알 수 없는 검술의 기억 | 처음 검을 쥠 · 생사의 고비 | 검 숙련 +3성 · 전생 기억 사건 |
| 숨은 천재 | 수련 50번 | 재능 하나가 천재(×2)로 |

| 귀신을 봄 | 무덤 · 귀물 사건 | 귀물 선택지 · 겁먹음 |

## 4. 전생 유산

### 규칙 (2부 C 제안 → 확정)
- 죽으면 **유산 후보 3개 중 1개**를 고른다. 짧은 생이면 후보 0~1개, 천수를 누리면 후보 4개.
- **유산 칸은 최대 5개.** 넘치면 하나를 버린다 → 시즌 안에서 무한히 강해지지 않는다.
- 회귀(시즌 끝)하면 전부 사라진다(W3).
- 후보는 **이번 생에 겪은 것**에서 나온다(검으로 살았으면 검의 깨달음, 독에 죽었으면 독 체질).

### 유산 목록

| 갈래 | 유산 | 효과 | 후보가 되는 생 |
|---|---|---|---|
| 깨달음 | 검술의 흔적 (도 · 권장 · 암기 · 신법 · 심법도 같은 꼴) | 다음 생 그 갈래 시작 성취 +2성 | 그 갈래 7성 이상 |
| | 벽의 기억 | 이번에 넘은 벽 하나 다음 생에 넘기 쉬움 | 벽을 넘은 생 |
| | 주화입마의 교훈 | 주화입마 위험↓ | 주화입마를 겪고 산 생 |
| 체질 | 독 내성 · 한빙 · 화령 등 | 2장 체질 하나 | 그 원인으로 죽었거나 오래 겪음 |
| 기억 | 익숙한 길 | 특정 지역 사건에서 선택지 하나 더 | 그 지역에서 오래 산 생 |
| | 숨겨 둔 곳 | 전생에 숨긴 물건의 위치(남이 가져갔을 수도) | 무덤 · 은닉을 한 생 |
| | 천기의 조각 | 회귀 비밀 한 줄 | 메인 핵심 사건을 겪은 생 |
| 인연 | 다시 만날 인연 | 특정 NPC가 다음 생에 우연히 나타남 · 첫 호감↑ | 신뢰 · 심복 NPC가 있던 생 |
| 원한 | 원수의 얼굴 | 나를 죽인 **NPC**를 알아봄 · 복수 선택지 | NPC에게 죽은 생 |
| 칭호 | 「백인참」 「신의」 「불사조」 등 | 작은 패시브 · 자랑 | 별호 · 기록이 큰 생 |
| 혈통 | 이름 없는 혈통 (매우 드묾) | 다음 생 희귀 · 전설 출신 확률↑ | 경지 화경 이상 또는 천수 |

## 5. 벽과 깨달음 (경지마다)

벽은 **숙련 · 내공이 가득 찬 뒤**에만 의미가 있다. 기본 확률(모의실험): 벽 앞에서 **수련 · 승리할 때 8%**, **중상에서 살아남으면 10%** — 그냥 오래 산다고 넘지 않는다. 벽 앞에 서면 화면에 `🧱 벽 앞`이 뜨고, 아래 길 중 하나가 열려야 넘는다.

| 벽 | 넘는 길 (하나면 됨) | 억지로 넘으면 |
|---|---|---|
| 삼류 → 이류 | 첫 실전 승리 3번 · 스승의 지도 | 가벼운 내상 |
| 이류 → 일류 | 같은 경지와 비무 10번 · 비급 정독(글 읽기) · 생사의 고비 | 내공 손실 |
| 일류 → 절정 | **생사의 고비에서 살아남음** · 절정 고수와의 비무 · 영약(소환단) | 경지 하락 위험 |
| 절정 → 초절정 | 자기 무공의 대성(12성) + 깨달음 사건(폭포 · 낚시 노인 · 고승의 한마디) | 영구 부상 위험 |
| 초절정 → 화경 | 대환단급 영약 · 신공 대성 · 큰 상실(소중한 인연의 죽음)을 겪음 | 수명↓ · 사망 위험 |
| 화경 → 현경 | 반로환동 사건 · 기연 · 천하제일고수와의 문답 | 사망 위험 큼 |
| 현경 → 생사경 | 시즌에 극소수. 「구유」와 관련된 깨달음(회귀 비밀) | — |

- 깨달음 사건 문장은 무공 성질 · 기운 · 성격에 맞춰 바뀐다(정 → "물 흐르듯", 마 → "끓어오르는 피").
- 생사의 선택(`wuxia-combat.md` 5장)의 "벽을 넘는다"는 이 표의 **생사의 고비** 길을 즉석에서 시도하는 것.

## 6. 사망 정산 화면 (최종 형태)

### 보통의 죽음
```
━━━━━━━━━━━━
☠️ 「진소운」 「혈영귀」 — 여기서 끝나다
━━━━━━━━━━━━
나이 29 (내 시간 15년) · 일류
사망 원인 └ 「흑룡」의 분파도 (흑룡도 앞바다)
이번 생 └ 혈교 수련장에서 살아남아 달아났고,
          남궁의 가면 무인을 쫓다가 바다에서 졌다.
처치 41 · 무공 6 · 주요 사건 23
━━━━━━━━━━━━
🎁 유산을 하나 고르세요 (칸 4/5)
 1 암기의 흔적 (+2성)
 2 독 내성
 3 원수의 얼굴 — 「흑룡」
━━━━━━━━━━━━
▸ 1행동 [번호]  → 다음 빙의
```
- **"이번 생"** 2~3줄은 생애 기록(사건마다 붙은 기록문)에서 뽑아 만든 짧은 전기(2부 C).

### 짧은 생 (행동 36번 미만)
```
☠️ 「무명」 — 너무 일찍 졌다
나이 16 · 삼류 · 사망 원인 └ 산적의 칼
🎁 남길 만한 것이 없다 (짧은 생)
▸ 다음 생엔 고정 출신 확률이 조금 낮다
```

### 천수 · 은퇴
```
🕊️ 「신의 백수」 — 천수를 누리다
나이 61 / 60 · 이류 · 객잔 「백수당」 주인
이번 생 └ 역병 도는 마을 셋을 살렸고,
          맹주의 지병을 끝내 고쳤다.
🎁 유산을 하나 고르세요 — 후보 4개
▸ 다음 생 좋은 출신 확률↑
```
