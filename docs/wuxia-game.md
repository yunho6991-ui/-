# 1부. 기획서 v0.1 (정한 것)

## 1. 개요

카톡 채팅방에서 명령어로 하는 **무협 세계관 생존형 텍스트 RPG**.
목표는 정답을 찾는 게임이 아니라 **매번 다른 인생을 살고, 죽음으로 다음 생에 이어지는 것**. 플레이어마다 무공·인연·사건·사망 원인·전생 유산이 달라 **각자의 무협소설**이 만들어지는 느낌.

**핵심 키워드**: 무협 / 생존 / 랜덤 / 전생 / 성장 / 인연 / 위험 / 예측 불가능성 / 각자의 무협소설

## 2. 핵심 철학

| # | 원칙 | 내용 |
|---|---|---|
| ① | 정답 공략을 어렵게 | 같은 행동이라도 만나는 NPC·사건·전투 상황·보상·위험·사망 여부가 달라진다. **랜덤이 핵심 시스템** |
| ② | 강함 ≠ 안전 | 강해질수록 위험한 곳에 가고 사망 위험도 커진다. 무기 파괴·부상·암기·기습·지형·독·외부 개입·상성·뜻밖의 NPC·특수 이벤트 → **강해도 방심하면 죽는다** |
| ③ | 죽음 = 성장 | 죽으면 대부분 잃지만 깨달음·경험 일부가 다음 생으로. "이번 생에서 최대한 얻고 죽자" |

## 3. 기본 루프

```
캐릭터 생성 → 강호 진입 → 수련/탐험/의뢰/교류 → 랜덤 사건
→ 무공·아이템·인연·명성 획득 → 더 위험한 지역 → 전투·사건
→ 사망 또는 생존 → (사망 시) 전생 정산 → 새 인생 → 유산 일부 계승 → 더 깊은 강호
```

## 4. 캐릭터 생성 — 시작부터 다른 인생

랜덤 요소: 출신 · **생김새** · 재능 · 체질 · 성격 · 초기 능력치 · 초기 무공 · 가족관계 · 초기 인연 · 숨겨진 특성

```
출신 : 몰락한 표국의 자식
생김새 : 험상궂은 얼굴 · 거구 · 왼뺨 칼자국
재능 : 검재(검 숙련 ×1.5)
성격 : 겁이 많음
체질 : 독에 강함
초기 무공 : 표국검
숨겨진 특성 : 알 수 없는 검술의 기억
특기 : 흥정(서툶) · 기마(능숙)
```

### 출신마다 진행이 다르다
출신은 능력치 차이가 아니라 **서막(출신 고유의 첫 이야기)과 평생 꼬리표**를 정한다. 예) 혈교에 납치된 백 명의 아이 중 하나로 잔인한 훈련을 받는다 · 남궁세가 자제로 태어난다 · 당가의 제자로 태어난다. 출신 틀·예시·목록: **`docs/wuxia-origins.md`**.

### 생김새 — 좋고 나쁨은 상대와 장소가 정한다
캐릭터를 만들 때 **얼굴 1 + 체격 1 + 특징 0~1개**가 랜덤으로 정해진다. 양 끝인 **절세미인 · 엄청나게 못생김**은 각각 1~2% 정도로 아주 드물게 나온다. 같은 생김새도 **상대 · 장소에 따라 이득이 되기도, 손해가 되기도** 한다. 잘생겨야 무조건 좋은 게 아니다.

| 얼굴 | 이득 | 불이익 |
|---|---|---|
| ✨ **절세미인** (아주 드묾 · 성별 무관) | 거의 모든 NPC 첫인상 최고, 후원자 · 혼담 · 호위 자청 사건↑, 설득 판정 크게↑ | **어디서든 눈에 띔**(변장 거의 불가, 추격자에게 바로 들킴), 납치 · 쟁탈 사건↑, 질투로 인한 암습↑, 나를 두고 세력끼리 다툼이 나기도 함 |
| 수려함 | 정파 · 세가 · 상인 첫인상↑, 혼담 · 인연 사건↑ | 눈에 잘 띔(추격자 · 미행에 잘 걸림), 질투 · 시비 사건↑ |
| 곱상함 | 의심을 덜 받음, 여인 · 노인 NPC 호감↑ | 사파에서 얕보임(시비↑), 위협 판정↓ |
| 평범함 | **잠입 · 변장 · 미행 판정↑**, 기억에 안 남음(추격자 잃기 쉬움) | 첫인상 보너스 없음, 인연 사건↓ |
| 순박함 | 마을 · 농민 · 거지 NPC 호감↑, 정보 얻기↑ | 사기 · 속임수 사건의 표적↑ |
| 험상궂음 | **사파 · 마교 · 산채 첫인상↑, 위협 판정↑**, 시비가 덜 붙음 | 정파 · 관아 · 마을 의심↑, 아이 · 상인이 피함 |
| 음침함 | 살수 조직 · 비밀 조직 · 정보상 호감↑, 은신↑ | 정파 · 관아 의심↑, 인연 사건↓ |
| 💀 **엄청나게 못생김** (아주 드묾) | **사파 · 마교에서 위압 최고**(시비가 거의 안 붙음), 미인계 · 유혹 면역, 외모를 안 보는 괴짜 고수 · 은거 기인이 제자로 받는 사건↑, 한 번 보면 잊지 못해 소문이 무기가 됨 | 정파 · 마을 · 관아 첫인상 최저(문전박대 · 의심 · 아이가 울음), 혼담 · 인연 사건 크게↓, 변장해도 체격 · 목소리 외엔 숨기기 어려움 |
| 요염함 (성인만) | 기루 · 사교 · 정보 캐기↑, 마교 일부 세력 호감↑ | 엮이기 싫은 사건(구애 · 납치 시도)↑, 정파 원로 불호 |

| 체격 | 이득 | 불이익 |
|---|---|---|
| 거구 | 위협↑, 힘 쓰는 의뢰↑, 사파 첫인상↑ | 은신 · 잠입↓, 눈에 띔 |
| 왜소 | 은신 · 잠입↑, 얕보여서 기습 성공↑ | 위협↓, 시비 표적↑ |
| 날렵 | 신법 수련 효율↑ | 힘 쓰는 의뢰↓ |
| 보통 | 변장 · 잠입 소폭↑ | 특별한 이득 없음 |

| 특징 (0~1개) | 효과 |
|---|---|
| 흉터 | 사파 · 무인 첫인상↑, 세가 · 혼담↓ |
| 이색 눈동자 | 마교 · 신비 사건↑, 마을 의심↑ |
| 백발(젊은데) | 은거 고수 · 기인 사건↑, 눈에 띔 |
| 문신 | 사파 · 수적 첫인상↑, 관아 의심↑ |

- **어떻게 쓰이나**: ① 세력 · NPC 첫인상(호감도 시작값) ② 사건 가중치(6장) ③ 판정 보정(위협 · 설득 · 잠입 · 변장). 화면엔 한 줄만: `생김새 : 험상궂은 얼굴 · 거구 · 왼뺨 칼자국`.
- **살면서 바뀐다**: 큰 부상 → 흉터 추가(험상궂은 쪽으로). 역용술 · 인피면구로 잠깐 바꿀 수 있다. 나이가 들면 곱상함 → 평범함 등.
- **다음 생엔 새 얼굴**: 생김새는 물려받지 않는다.
- **정체의 단서**(W5): 다른 사람에게도 생김새가 보인다. "칼자국 있는 거구한테 당했어" → 방에서 "어, 나 그렇게 생겼는데?"가 단서가 된다. 다시 태어나면 얼굴이 바뀌어 단서도 사라진다.
- 출신에 따라 생김새 확률이 조금 기울 수 있다(예: 산채의 아이는 험상궂음 · 흉터↑, 세가 자제는 수려함↑).

### 재능 — 숙련이 오르는 속도
- 재능은 **무엇을 할 수 있느냐가 아니라, 얼마나 빨리 느느냐**를 정한다. 타고나서 바뀌지 않는다.
- 무공(검 · 도 · 권장 · 암기 · 신법 · 내공)과 특기 갈래(지식 · 생존 · 손재주 · 사교 · 은밀) 중 어딘가에 붙는다.

| 재능 | 숙련 오르는 속도 | 예 |
|---|---|---|
| 천재 (아주 드묾) | ×2 | 검의 천재 · 의술의 천재 |
| 재능 있음 | ×1.5 | 검재 · 손재주가 좋음 |
| 보통 | ×1 | (표시 안 함) |
| 둔함 | ×0.6 | 몸치(신법) · 글눈이 어두움(지식) |

- **시작 때 재능 1~2개 + 둔함 0~1개**가 랜덤. 출신이 조금 기울인다(당가 → 독술 재능↑, 혈교 아이 → 암기 · 신법↑).
- 재능이 없는 갈래도 배울 수는 있다. 느릴 뿐.
- **둔한 갈래를 달인까지 올리면** 특별 기록(「노력의 검」 같은 칭호 후보) — 재능 없는 인생도 이야기가 된다.
- 전생 유산 "깨달음"은 재능을 바꾸지 않고 숙련 시작점을 올려 준다(재능은 매 생 새로 굴림).
- 화면: `재능 : 검재(×1.5) · 글눈 어두움(×0.6)`

### 특기 — 할 줄 아는 일

> **재능 = 타고난 성장 속도**(안 바뀜), **특기 = 할 줄 아는 일**(배우고 잃는다). 무공이 "싸우는 법"이라면 특기는 "싸움 말고 사는 법".

#### 핵심: 특기는 숫자보다 **선택지를 연다**
- 사건이 뜨면 내 특기에 맞는 **선택지가 하나 더 생긴다.** 특기가 없으면 그 길은 아예 안 보인다.
  - 예) 부상자를 만남 → `의술`이 있으면 "치료한다"(인연 · 은혜) / 없으면 지나치거나 돈만 줄 수 있음
  - 예) 잠긴 상자 → `자물쇠 따기` "연다" / 없으면 부수기(소리 · 내용물 파손 위험)
- 같은 사건도 특기에 따라 다른 결말 → **정답 공략이 하나로 안 굳는다**(기획서 철학 ①).

#### ⭐ 글 읽기 — 가장 무협다운 특기
- **문맹이 기본값인 출신이 많다**(농부 · 거지 · 사냥꾼 · 혈교 아이 …).
- 비급을 주워도 **글을 못 읽으면 못 익힌다.** 팔거나, 글 아는 사람에게 읽어 달라고 하거나(내용이 새거나 뺏길 위험), 글을 배우거나.
- 세가 · 문파 · 상단 출신은 처음부터 가진다.

#### 특기 목록 후보

| 갈래 | 특기 |
|---|---|
| 지식 | 글 읽기 · 의술 · 독술 · 진법 · 감정(물건 값 · 진위 알아보기) · 지리 |
| 생존 | 사냥 · 약초 캐기 · 추적 · 수영 · 기마 · 동물 다루기 |
| 손재주 | 대장일 · 자물쇠 따기 · 요리 · 암기 손질 |
| 사교 | 말재주 · 흥정 · 도박 · 악기 · 연기(거짓말) · 술 세기 |
| 은밀 | 은신 · 소매치기 · 역용술(변장) · 독 타기 |

#### 규칙
- **시작 1~2개**: 출신이 정한다(당가 → 독술, 사냥꾼 → 사냥 · 추적, 객잔 아이 → 흥정 · 말재주).
- **배우는 법**: 사건으로 배운다(의원을 도우면 의술, 도박판에서 살아남으면 도박). 수련 행동으로도 천천히.
- **숙련 3단계**: 서툶 → 능숙 → 달인. 단계가 오를수록 선택지가 더 열리고 성공률↑.
- **칸 제한**: 동시에 최대 4~5개. 넘치면 하나를 잊는다 → 한 생에 다 가질 수 없어서 인생마다 색이 달라짐.
- **숨은 특기**: 본인도 모르는 특기가 하나 있을 수 있다. 사건 중에 갑자기 드러난다("처음 잡은 활인데 손에 익다"). 4장 "숨겨진 특성"과 연결.
- **전생 유산**: 전생의 특기 하나가 다음 생의 **숨은 특기**로 남을 수 있다(9장 "기억"과 연결).
- **생김새와 엮임**: 평범한 얼굴 + 역용술 = 잠입의 달인, 절세미인 + 말재주 = 세력을 움직임, 엄청나게 못생김 + 연기 = 아무도 의심 못 함.
- **정체의 단서**(W5): "독을 타는 놈이었어" 같은 말이 방에서 단서가 된다.

#### 화면
`특기 : 글 읽기(능숙) · 독술(서툶) · 흥정(달인)` — 한 줄.

## 5. 랜덤 사건 (핵심)

행동을 고르면 결과는 **지역별 사건 테이블**에서 랜덤으로 정해진다.

- 예) 산 탐험 → 야생동물 · 산적 · 무림인 · 상인 · 은둔 고수 · 비급 · 보물 · 부상자 · 신비한 동굴 · 자연재해 · 독초 · 희귀 NPC · 아무 일 없음 · 특수 이벤트 · 사망 이벤트

| 지역 | 사건 테이블 |
|---|---|
| 산 | 야생동물 · 산적 · 약초 · 은둔 고수 · 동굴 |
| 마을 | 상인 · 주점 · 도박 · 의뢰 · 정보 · 사건 |
| 무림맹 | 문파 · 무림인 · 의뢰 · 경쟁 · 정치 사건 |

### 세상에 하나뿐인 기연 (확정)
- 고정 출신(W8)처럼 **세계에 정원이 있는** 비급 · 신병이기 · 영약. 대부분 정원 1. 예) 「천마신공」 한 권 · 「태아검」 한 자루 · 「만년설삼」 한 뿌리.
- **세계 공유**(W6): 모든 방을 통틀어 하나. 시즌(세계관 리셋)이 끝날 때까지 목록이 정해져 있다.
- **얻으면 소문만 돈다**(W7): "누군가 「천마신공」을 손에 넣었다는 소문이 돈다" — 누가 얻었는지는 안 밝힌다. 모두가 찾아다니는 대상이 된다.
- **주인이 죽으면 다시 강호로 돌아간다**: 죽인 자가 가져가거나(W2), 강호 어딘가의 사건으로 다시 숨는다. 그래서 기연은 시즌 내내 쟁탈 대상.
- 비급은 **글 읽기**(특기)가 없으면 익힐 수 없다 — 손에 넣고도 못 쓰는 기연.
- 정원 소진형(영약처럼 먹으면 사라짐)과 순환형(신병 · 비급처럼 주인이 바뀜)을 나눈다.

## 6. 랜덤은 내 상태에 따라 기운다

| 상태 | 테이블 변화 |
|---|---|
| 거지 출신 | 거지 NPC↑ · 돈 사건↑ · 숨겨진 정보↑ |
| 사냥꾼 출신 | 야생동물 사건↑ · 사냥 성공률↑ · 희귀 재료 |
| 악명 높은 무인 | 현상금 사냥꾼 · 적대 NPC↑ · 특정 세력 관계 악화 |

## 7. 전투

능력치(체력 · 내공 · 공격 · 방어 · 속도 · 명중 · 회피 · 치명 · 독/상태이상 · 무공 숙련) + **전투 중 랜덤 이벤트**.

```
당신의 검이 상대의 암기에 맞았다. [무기 내구도 감소]
상대가 숨겨둔 독침을 사용했다. [독 상태]
갑자기 지나가던 무림인이 전투에 개입했다.
```

### 경지와 벽 (확정)
- 경지: **삼류 → 이류 → 일류 → 절정 → 초절정 → 화경 → 현경 → 생사경**.
- 경지마다 **벽**이 있다. 숙련 · 내공만 쌓아서는 못 넘고, **깨달음 사건**(기연 · 생사의 고비 · 고수와의 비무 등)을 겪어야 넘는다 → 누구는 일찍, 누구는 평생 못 넘는다.
- 사망 정산의 "최종 경지"와 강호 소식 · 랭킹의 기준.
- 생김새 · 별호처럼 다른 사람에게 보이는 정보: `「남궁 휘」 (일류 · 사파)`.

### 별호 (확정)
- 행적에 따라 **자동으로 붙는 별명**: 「흑면귀」(험상궂은 얼굴 + 사파) · 「외팔 검객」(불구 + 검) · 「독수 낭자」(독술 + 여성) · 「백인참」(처치 100).
- 생김새 · 무공 · 특기 · 행적(처치 수 · 독 사용 · 배신 · 구출) 조합으로 정해지고, 더 큰 행적이 생기면 **바뀐다**. 아직 행적이 없으면 「무명」.
- **강호 소식(W7)엔 별호로 뜬다**: "「흑면귀」가 무림맹 장로를 쓰러뜨렸다". 유명해져도 그게 누군지는 모른다(W5) — 자랑과 익명이 같이 산다.
- 다음 생엔 새 별호. 지난 생의 별호는 사망 정산 · 내 전기에 남는다.
- 현상금 · 원한은 별호로 걸린다(이름보다 별호가 먼저 알려짐).

**전생 기억 예**: 1회차 산적에게 사망 → 2회차 같은 곳에서 "이상하게 이 길이 익숙하다"(선택지 열림) → 3회차 전생 검술 일부 기억 → 4회차 전생의 원수(NPC)를 알아봄 → 여러 생에 걸쳐 강호의 비밀을 알아감.

**다 물려받지 않는다**

| 남을 수 있는 것 | 잃는 것 |
|---|---|
| 일부 깨달음 · 일부 무공 숙련 · 특수 칭호 · 체질 · 전생 기록 · 특정 인연 · 일부 기억 | 돈 · 일반 장비 · 현재 명성 · 문파 지위 · 대부분의 인간관계 · 진행 중 의뢰 · 신체 상태 |

### 나이와 수명 (확정)
- **기본 최대 수명 60세.** 다치지 않고 살아남아도 60이 되면 생이 끝난다(자연사도 사망 정산).
- **경지와 기연으로 늘린다**(아래 숫자로 시작, 조정 가능):

| 수명을 늘리는 것 | 최대 수명 |
|---|---|
| 기본 | 60 |
| 절정 | +10 (70) |
| 초절정 | +20 (80) |
| 화경 | +40 (100) |
| 현경 | +60 (120) · **반로환동**(젊은 몸으로 돌아감) 사건 |
| 생사경 | +100 (160) |
| 영약 기연(만년설삼 등) | 하나당 +10~30 |

- **줄어들기도 한다**: 주화입마 · 중상 · 독 후유증 · 마공 대가로 최대 수명↓. 강해지려다 수명을 깎는 선택도 생긴다.
- **시작 나이는 출신이 정한다**(혈교 아이 7세 · 세가 자제 12세 · 낭인 20세 등).
- **나이에 따른 변화**: 40대부터 신체(체력 · 신법)가 조금씩↓, 깨달음 사건↑ — 늙은 고수가 젊은 천재를 이기는 이야기.
- 화면: `나이 : 34 / 70` (지금 / 최대 수명).
- **시간 흐름(확정, 일단 이대로 시작)**: **행동 1번 = 강호 시간 10일**, **하루 행동 20번**까지 → 실제 하루에 강호 약 반년. 15세 시작이면 60세까지 실제 약 3달(대부분 그 전에 죽음). 플레이테스트 보고 조정.

### 빠른 사망 리롤 막기 (확정)
죽어야 다음 생이 오므로, 일부러 빨리 죽어 좋은 출신 · 고정 출신을 노리는 걸 막는다.
- **짧게 산 생은 남기는 게 없다**: 생존 기간 · 겪은 사건 수가 적으면 유산 후보 · 숨은 특기 후보가 거의 안 나온다.
- **고정 출신 확률도 깎인다**: 직전 생이 짧았으면 다음 생에 고정 출신(정원 있는 출신)이 나올 확률↓.
- **서막에서 죽어도 마찬가지**: 서막 중 사망은 "짧은 생"으로 친다(고정 출신 정원은 그대로 소진, W8).
- **기준(확정)**: 강호 시간 **1년 미만**(= 행동 약 36번 미만, 실제로 2일 남짓)을 산 생은 "짧은 생".

## 10. 강호 · 세력 · NPC

- **지역**: 초반 마을/산/강/작은 문파 → 중반 대도시/유명 문파/무림맹/사파 → 후반 금지구역/마교/고대 유적/북방/황궁 → 최종 천하의 비밀/전설의 영역. 지역마다 사건·NPC 테이블이 다르다.
- **세력**: (원안) 정파 · 사파 · 마교 · 세가 · 표국 · 상단 · 황실 · 무림맹 · 비밀 조직 → **확정 목록은 `wuxia-world.md` 3장**(무림맹 = 왕권, 소림 · 화산 · 무당, 제갈 · 남궁 · 사천당가 · 하북팽가, 개방, 마교 · 혈교, 녹림 · 수적). 가입 · 승급 · 탈퇴 · 배신 · 추방 · 적대 · 동맹.
- **NPC 데이터**: 이름 · 성격 · 소속 · 경지 · 관계 · 호감도 · 적대도 · 비밀 · 보유 무공 · 현재 위치 · 플레이어와의 기억. 같은 NPC도 플레이어마다 관계가 다르다.
- **NPC도 움직인다**: 문파 전쟁 · NPC 성장/사망 · 세력 흥망 · 새 고수 · 상단 이동 · 지역 변화. "내가 주인공이 아니라 강호에 사는 한 사람".

## 11. 콘텐츠와 코드 분리

| # | 결정 | 내용 |
|---|---|---|
| W1 | **톤** | 사망 · 원한 · 악연 · 배신 모두 쓴다. 문체는 무협소설 |
| W2 | **유저끼리 손해 있음** | 유저끼리 싸움 · 약탈 · 원한 · 배신 가능. 다른 유저도 강호의 위험 요소 중 하나 |
| W3 | **시즌제 = 세계 회귀** | 시즌이 바뀌면 세계가 같은 시작 시점으로 **회귀**. 캐릭터 쪽(빙의 인물 · 유산 · 기억 · 원한 · 기록 · 기연)은 **전부 초기화**, 남는 건 시즌 보상(칭호 등)과 플레이어 머릿속 기억뿐. 세계 뼈대는 같지만 사건 시기 · 조건 · 결과는 회차마다 달라진다(`wuxia-world.md` 1-3) |
| W4 | **시즌은 큰 업데이트 때 끝낸다** | 정해진 기간 없음. 큰 업데이트가 필요해지면 그때 시즌을 닫고 새 시즌 시작 |
| W5 | **누가 유저인지 모른다** | 다른 유저의 캐릭터는 NPC와 **똑같이** 보인다. 직접 말하기 전까지는 그 무인이 사람인지 NPC인지 알 수 없다. 유저 원수가 다시 태어나면 **아무 힌트도 없다**(전생 기억으로 알아보는 건 NPC 원수뿐) |
| W6 | **다른 방 유저와도 섞인다** | 강호는 모든 방이 함께 쓰는 하나의 세계. 내가 만난 무인이 같은 방 사람일 수도, 다른 방 사람일 수도, NPC일 수도 있다. 방마다 끌 수 있는 설정 하나를 둔다(끄면 그 방 사람끼리만 만남) |
| W7 | **강호 소식은 전체** | 방에 올라가는 강호 소식은 모든 방 공통(강호 전체의 사건). 강호 이름만 쓰고 누구 방인지·유저인지 NPC인지는 안 밝힌다 |
| W8 | **고정 출신은 정원이 있다** | 혈교에 납치된 아이 5번 · 천하제일고수의 제자 1~2번 · 성녀 1번처럼 **세계관 리셋까지 나올 수 있는 횟수**가 정해진 출신. 빈자리는 NPC가 채우고, 유저가 그 출신을 뽑으면 **그 NPC에 지금 상태 그대로 빙의 + 일지 보기**. 한 사람은 같은 고정 출신을 **한 시즌에 한 번만**. 후계 다툼이 있는 세가(예: 남궁)도 고정 출신 · 공유 서막(`wuxia-origins.md` 2장) |
| W9 | **빙의** | 플레이어는 세계에 원래 있던 인물에게 빙의한다(출신 = 그 인물의 배경). 죽으면 다른 인물에게 빙의(= 다음 생) |
| W10 | **퓨전무협** | 인간 외에 요수 · 요괴 · 영물 · 귀물이 산다. 인간 대 요괴의 선악 구도가 아니다 |

## 16. 최종 목표

"어디로 가야 효율적이지?"보다 **"이번 생에는 대체 무슨 일이 벌어질까?"**.
죽었을 때 "처음부터 다시네"가 아니라 **"이번 생은 여기까지구나. 다음 생에는 저놈을 반드시 찾아간다."**

# 2부. 검토 메모 (제안)

> 기획 방향은 좋다 — "죽음이 콘텐츠"와 "각자의 무협소설"은 카톡 텍스트에 잘 맞는다. 아래는 카톡 봇으로 만들 때 걸리는 점과 단순화 제안.

## A. 유저끼리 손해(W2) + 정체 모름(W5) 만들 때 생각할 점

> 핵심: **유저는 NPC 속에 섞여 있다.** "그 산적, 혹시 너였어?"가 방에서 터지는 순간이 이 게임의 명장면.

### 섞여 보이게 하기
| 제안 | 내용 |
|---|---|
| **이름은 강호 이름만** | 캐릭터 이름은 NPC와 같은 이름 생성기로 랜덤(예: 「남궁 휘」). 카톡 닉네임은 게임 안 어디에도 안 나온다 |
| **표시 형식 통일** | 유저 캐릭터도 NPC와 같은 줄 형식: `흑의 무인 「남궁 휘」 (일류 · 사파)`. "유저" 표시 · 접속 표시 없음 |
| **유저도 NPC처럼 움직인다** | 상대 유저가 자리에 없어도 그 캐릭터의 성격 · 성향대로 자동 대응. 그래서 "답이 늦다 = 사람" 같은 티가 안 난다 |
| **NPC도 유저처럼 보인다** | 일부 NPC는 유저처럼 이름 · 성장 · 행동 기록을 갖는다(15장 "NPC도 움직인다"). 섞어 놓아야 구분이 안 된다 |
| **만남 알림도 같게** | 상대 유저 쪽 결과도 "산길에서 한 무인과 마주쳤다" — 양쪽 다 상대가 사람인지 모른다 |

### 정체가 새는 곳 막기
| 새는 곳 | 막는 법 |
|---|---|
| 방 강호 소식 · 랭킹 | 강호 이름만 쓴다. 카톡 닉네임과 연결하지 않는다 |
| 사망 정산의 "사망 원인" | `「남궁 휘」의 장법` — 사람이었는지는 안 알려 준다 |
| 행동 타이밍 | 유저끼리 만남도 내 행동 때 사건으로 처리(상대가 그 시각에 뭘 했는지와 무관) |
| 같은 방 사람만 의심하면 됨 | 다른 방 유저와도 섞인다(W6) — 범인이 우리 방에 없을 수도 있다 |

### 원한 · 전생과 이어지기
| 제안 | 내용 |
|---|---|
| **원수도 새 이름으로 다시 태어난다** | 나를 죽인 유저가 죽고 다시 태어나면 이름이 바뀌고 **아무 힌트도 없다.** 다시 만나도 모른다 → 방에서 직접 물어봐야 확인 |
| **약탈 범위** | 뺏는 건 돈 · 일반 장비 일부 + **기연 물건**(5장). 유산 · 기억은 못 뺏는다(죽은 쪽도 다음 생이 남게) |
| **약자만 노리는 고수** | 약자를 죽이면 악명↑ → 현상금 사냥꾼(6장)이 붙는다. 그 사냥꾼이 NPC인지 유저인지도 모른다 |

### 정체 밝히기
- 기본은 **게임 밖(카톡 대화)**에서 직접 말하는 것. 게임은 확인해 주지 않는다 → 거짓말도 가능("그거 나 아니야").

## B. 카톡에서 만들 때 걸리는 점

1. **명령 수**: 행동이 많아도 명령은 적게. 단순화 버전:
   - `1강호` — 처음이면 캐릭터 생성, 아니면 내 상태 + 지금 할 수 있는 행동 번호 목록
   - `1행동 [번호]` — 목록에서 고르기(수련·탐험·의뢰·교류·이동, 사건 중 선택지 모두 번호로)
   - ⚠️ 이름이 기존 봇 명령과 겹치는지 확인
2. **선택지 대기에 시간 제한을 두지 않는다**: 사건 중 선택지가 뜨면 몇 시간 뒤에 답해도 된다(시간 압박 금지). 대신 대기 중엔 다른 행동 불가.
3. **능력치는 보이는 건 4~5개만**: 체력 · 내공 · 무공(공격) · 신법(속도·회피) · 경지. 명중·치명·방어 등은 무공·체질 안에 숨겨서 계산. 메시지 한 장에 다 들어가야 한다.
4. **결과 메시지 길이**: 사건 하나 = 3~6줄. 사망 정산만 예외로 길게(자랑용 캡처 포인트).
5. **방(단체톡)과 개인톡**: 플레이는 개인톡, 방에는 **강호 소식만**(누가 죽었다·전설 무공 획득·NPC 고수 등장). 소식은 모든 방 공통(W7).

## C. 재미를 키우는 제안

| 제안 | 내용 | 단순화 |
|---|---|---|
| **생애 기록 → 짧은 전기** | 주요 사건이 기록에 쌓이고, 사망 정산에 3~5줄 "○○전(傳)"으로 묶어 준다. "각자의 무협소설"을 문자 그대로 구현 | 사건 데이터에 `기록문` 한 줄씩만 넣으면 됨 |
| **유산은 고르게** | 사망 시 유산 후보 3개 중 1개를 고른다(전부 주지 않음 → 강해지기만 하는 것 방지, 고르는 재미) | 후보 3개 → 1개 |
| **유산 칸 제한** | 동시에 가질 수 있는 유산 최대 n개. 넘치면 교체 | n = 3~5 |
| **원한의 상대는 NPC로 남는다** | 나를 죽인 NPC가 세계에 계속 존재하고 성장한다. 다음 생에 다시 만날 확률↑ | 사망 원인 NPC id만 저장 |
| **강호 시간은 하루 단위로** | NPC 행동·세력 변화는 하루 한 번 일괄 계산(실시간 X). 서버 부담↓, "어제 무림맹에서…" 소식거리 | 하루 1회 배치 |
| **세계는 공유, 관계는 개인** | NPC 위치·생사·세력은 모든 플레이어 공통, 호감도·기억은 플레이어별 | 데이터 두 층 |
| **방 자랑거리** | 최장 생존 · 최고 경지 · 최다 전생 · 희귀 사망 원인 도감 | 기록만 모으면 됨 |

## D. 범위 · 일정 위험

- Phase 1~3 = 시스템 25개. "완성 후 공개"라면 **완성이 계속 밀릴 위험**이 가장 크다.
- 제안: 공개는 완성 후 그대로 하되, 내부적으로는 **"작은 강호" 한 판**부터 끝까지 만든다.
  - 지역 3개(마을 · 산 · 작은 문파) · 세력 2개 · NPC 10명 · 사건 60개 · 무공 15개 · 유산 10종
  - 이걸로 Phase 4 방식 테스트까지 돌려 보고, 재밌으면 지역·사건을 데이터로만 늘린다(코드 분리 원칙 덕).
- 한 생의 길이 목표를 먼저 정하기: 예) 보통 3~7일(하루 행동 n번 기준). 이게 정해져야 사망 확률·성장 속도를 맞출 수 있다.

## E. 사건 데이터 예시 (11장 구조를 그대로)

```yaml
- id: mountain_bandit_01
  name: 산적의 통행세
  region: 산
  weight: 30            # 기본 확률 가중치
  weight_mod:           # 6장 — 상태에 따라 기울기
    출신=거지: -10
    명성>=50: +20
  require: []           # 선행 사건
  text: "좁은 산길에서 산적 셋이 길을 막는다. \"통행세를 내라!\""
  choices:
    - text: 돈을 낸다
      result: {돈: -30%}
    - text: 싸운다
      result: {battle: bandit_x3}
    - text: 도망친다
      result: {check: 신법, success: 무사, fail: {부상: 경상}}
  death_possible: true
  record: "산길에서 산적 셋을 만났다"     # 생애 기록 한 줄

```

## H. 더 넣을 만한 것 (제안)

### 꼭 필요한 것 — 빠지면 구멍
| 항목 | 내용 |
|---|---|
| ~~경지 체계~~ → **1부 7장으로 확정** | 삼류 → 이류 → 일류 → 절정 → 초절정 → 화경 → 현경 → 생사경. 경지마다 **벽**이 있어 깨달음 사건이 있어야 넘는다. 사망 정산 "최종 경지"의 기준 |
| **주화입마** | 벽을 억지로 넘거나 맞지 않는 무공을 섞으면 내공 폭주 → 부상 · 경지 하락 · 사망. 강함 ≠ 안전(철학 ②)의 대표 |
| ~~시간 · 나이 · 수명~~ → **나이 · 수명은 1부 9장으로 확정**, 시간 흐름만 남음 | 행동 1번 = 강호 시간 며칠. 나이를 먹고, 늙으면 신체↓ · 깨달음↑, 결국 **수명으로 죽는다**(자연사도 정산). "생존 기간"의 기준 |
| **부상 단계** | 경상(며칠) → 중상(오래) → **불구**(한 팔 · 한 눈 등 영구). 불구가 돼도 인생은 계속 — 외팔 검객 같은 이야기 |
| ~~빠른 자살 리롤 막기~~ → **1부 9장으로 확정** | 죽어야 다음 생이면, 일부러 빨리 죽어 좋은 출신을 노리는 문제가 생긴다. 생존 기간이 짧으면 유산 · 숨은 특기 후보가 거의 없고, 고정 출신 확률↓ |

### 재미를 키우는 것
| 항목 | 내용 |
|---|---|
| ~~별호~~ → **1부 7장으로 확정** | 행적에 따라 자동으로 붙는 별명: 「흑면귀」 「외팔 검객」 「독수 낭자」. 강호 소식엔 별호로 뜬다 → 유명해져도 정체는 모름(W5). 자랑과 익명이 같이 산다 |
| **무덤과 유품** | 죽기 전에 비급 · 신병을 숨기거나 무덤에 남길 수 있다. **다른 유저(또는 다음 생의 나)가 그걸 줍는다.** 누구의 것이었는지는 모름 |
| **자식으로 다시 태어나기** | 혼인해 자식이 있으면, 다음 생을 **내 자식으로** 시작할 수 있는 출신 후보가 뜬다. 혈통 유산(9장)의 구체적인 모습. 원수가 내 자식을 노릴 수도 |
| ~~세상에 하나뿐인 기연~~ → **1부 5장으로 확정** | 고정 출신처럼 정원 1인 비급 · 신병이기(예: 「천마신공」 한 권). 누가 얻으면 소문만 돈다 → 모두가 찾아다니는 대상 |
| **현상금** | 별호 · 생김새로 현상금을 걸 수 있다. 사냥꾼이 NPC일 수도 유저일 수도 |
| **은퇴(귀은)** | 죽지 않고 스스로 강호를 떠나 생을 마무리. 사망보다 유산 선택지가 하나 더(평온한 끝도 하나의 결말) |
| **강호 대사건** | 시즌 중 정해진 큰 사건(정마대전 · 무림대회 · 마교 교주 교체). 모든 유저가 같은 시기에 휘말린다. 강호 소식(W7)의 큰 줄기 |
| **내 전기 · 역대 인생** | 지난 생들의 사망 정산을 모아 보기. "3번째 생: 외팔 검객, 47일, 혈마의 장법" |

## F. 정할 것

| 질문 | 메모 |
|---|---|
| 게임 안에서 정체를 밝히는 선택지 | 넣지 않음(추천, 직접 말하기만) / 대화 사건에 "정체를 밝힌다" 선택지 |
| 시즌 보상 | 최고 경지 · 최장 생존 · 최다 전생 · 희귀 사망 원인 등 기록 칭호 |
| 하루 행동 횟수 · 한 생 길이 목표 | 밸런스 기준점 |
| 명령 이름 | `1강호` · `1행동` 겹침 확인 |
| 그림(컴피) 쓸지 | 텍스트 게임이지만 전설 NPC·사망 정산 카드 정도는 그림이 있으면 자랑거리 |
