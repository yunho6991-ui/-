# 무협 게임 — ComfyUI 그림 프롬프트 (Krea2 · 자연어 영어)

> 핵심 NPC · 히로인 · 남성 인연 · 장소. 낚시 게임 화풍(`art-cute-prompts.md`)과 **별개** — 무협 게임은 이 문서의 문구를 쓴다.
> 사용법: **[문구]** + 매력 꼬리 + 인물 묘사. 초상 832×1216, 장소 1216×832.
> 규칙: 섹시 · 요염은 **성인만, 옷은 다 입은 채로, 품위 있게**. 미성년(17세 이하)은 평범한 모습만. 잔혹 · 유혈 묘사 없이 분위기로만.
> 각 줄 맨 앞 `[ ]`는 다시 뽑기 체크.

---

## 문구 (화풍 고정)

**[무협 인물]**
```
A detailed East Asian wuxia fantasy character portrait, painterly illustration with subtle ink-wash textures and rich colors, flowing layered robes, cinematic rim lighting, expressive face, upper body, soft misty background, no text, no letters, no watermark.
```

**[무협 장면]** (장소)
```
A wide East Asian wuxia fantasy landscape, painterly illustration with ink-wash mist and rich colors, atmospheric depth, small human figures for scale, cinematic light, no text, no letters, no watermark.
```

**[요괴]** (요괴 · 요수 · 영물)
```
A mysterious East Asian folklore spirit creature, painterly wuxia fantasy illustration with ink-wash mist, eerie but beautiful, glowing eyes, elegant silhouette, no gore, no text, no watermark.
```
