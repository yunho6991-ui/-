# 무협 게임 — 공용 사건 · 꼬리표 사건 (1차 묶음)

> 세계관 바이블 ⑦. 사건 데이터 형식(`wuxia-game.md` 2부 E + `wuxia-world.md` 1-5)을 따른다.
> 이 문서는 **기획용 요약 표**. 실제 데이터로 옮길 때 사건 하나 = YAML 한 덩어리(맨 아래 예시).
> 1차 묶음: 초반 · 중반 지역 위주 **70개**. 후반 지역(북방 설원 · 십만대산 · 흑룡도 · 청구 · 남쪽 습지)은 2차.

## 표 읽는 법

| 칸 | 뜻 |
|---|---|
| 가중 | 기본 확률 가중치(높을수록 자주). `↑태그`는 그 꼬리표 · 상태면 더 자주 |
| 조건 | 없으면 언제나. `n막`은 시즌 사건 줄기와 엮인 사건 |
| 선택 → 결과 | 대표 선택지. 특기 · 생김새로 열리는 선택지는 [대괄호] |
| 세계 | 세계 변수 · 호감도 · 꼬리표 변화 |

### 원칙
- **꽝은 없다**: "아무 일 없음"도 짧은 풍경 + 작은 것 하나(소문 · 숙련 · 호감)를 남긴다.
- **사망 가능 사건**은 이름 뒤 ☠. 경고 문장이 먼저 나온다.
- 모든 사건은 **기록문 한 줄**(사망 정산 · 전기용)을 가진다 — 표에선 생략.

- id: v09
  name: 사라진 아이
  region: 마을
  weight: 12
  require: {act: [1, 2]}          # 시즌 1막~2막에만
  death_possible: true
  text: "이웃집 아이가 밤새 돌아오지 않았다. 문간에 붉은 진흙 발자국이 찍혀 있다."
  choices:
    - text: 찾아 나선다
      next: v09_track              # 3단 연속 사건
    - text: 관아에 알린다
      result: {world: {ritual: +3}, affinity: {관아: +1}}
    - text: 모른 척한다
      result: {world: {ritual: +5}, affinity: {마을: -2}}
  record: "사라진 이웃집 아이의 일을 겪었다"
  memory_key: blood_cult_kidnap
