# 무협 게임 — 만날 수 있는 히로인

> 강호에서 만나 인연을 맺을 수 있는 핵심 여성 NPC. 데이터 틀은 `wuxia-npcs.md`(목표 · 비밀 · 행동 · 사망 조건)에 **인연 이야기**를 더한다.
> 모두 **성인**. 생김새 · 성격은 서로 겹치지 않게 — 아름답거나 · 귀엽거나 · 섹시하거나 · 강하거나.

---

## 1. 인연 규칙

| 규칙 | 내용 |
|---|---|
| 호감은 숨김 | 기존 호감도 그대로(원수 ~ 심복). 히로인은 그 위에 **연모**가 하나 더 있다(신뢰 이상에서 열림) |
| 인연 단계 | 만남 → 관심 → 신뢰 → **연모** → **혼인** (또는 이별 · 배신 · 죽음) |
| 연모는 개인별, 혼인은 하나 | 여러 플레이어가 같은 히로인과 연모까지 갈 수 있다. **혼인은 세계에 한 번** — 먼저 혼인한 사람이 있으면 다른 이들은 "그녀가 누군가와 혼인했다"는 소식을 듣는다(그 누군가가 유저인지는 모름, W5) |
| 히로인은 혼자 움직인다 | 플레이어가 없어도 목표대로 행동하고, 성장하고, **죽을 수 있다**(메인 사건). 지켜 주지 않으면 잃는다 |
| 회귀 | 시즌이 끝나면 처음으로 돌아간다. 그녀는 나를 모르지만, **나는 지난 회차의 그녀를 기억한다** — "지난번엔 지키지 못했다" |
| 빙의 | 히로인은 빙의 대상이 아니다. 단, **마교 성녀**는 고정 출신(정원 1)이라 유저가 그 자리에 빙의할 수 있다(그러면 성녀가 유저) |
| 성별 | 빙의한 인물의 성별과 상관없이 인연은 열린다(정할 것 — 남성 인연 캐릭터도 같은 틀로 만들지) |
