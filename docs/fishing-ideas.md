## 1. 버그·안정성

### 🔴 1-1. 같은 사람이 동시에 보낸 명령이 겹치지 않게 막기
- **문제**: `_cast`가 "기다리는 찌 확인 → 미끼 확인 → 던지기 기록" 순서로 처리하는데, 그 사이에 잠금이 없다.
  웹훅이 여러 스레드에서 처리되면 `1낚시`를 빠르게 두 번 쳤을 때 둘 다 통과해서 찌가 두 개 던져지거나, 마지막 미끼 1개로 두 번 낚을 수 있다.
- **같은 위험이 있는 곳**: `_bulk`, `_raid`, `_upgrade`, `_buy_bait`, `_exchange` 등 포인트·미끼가 줄어드는 명령 전부.
- **방법**: `dm_handle` 맨 앞에 사람별 잠금을 건다. `_gift_lock`이 이미 있으니 같은 방식으로 하면 된다.
  ```python
  _person_locks: Dict[str, threading.Lock] = {}
  _locks_guard = threading.Lock()

  def _lock_for(raw: str) -> threading.Lock:
      with _locks_guard:
          return _person_locks.setdefault(raw, threading.Lock())

  # dm_handle 안에서
  with _lock_for(raw):
      ...기존 처리...
  ```
- **확인할 것**: Flask를 `threaded=True`로 띄우는지 확인한다. 요청을 하나씩만 처리한다면 급하지 않다.

### 🟡 1-2. 연결 코드(`_codes`) 정리
- 메모리에만 있어서 재시작하면 사라지고(이건 괜찮다), 만료된 코드가 지워지지 않고 쌓인다.
- `1연결` 할 때 만료된 코드를 한 번씩 지우면 된다.

### 🟡 1-3. 타이머가 많이 쌓이는 문제
- `threading.Timer`를 낚시 한 번마다 하나씩 만든다(파일 전체에 12곳). 사람이 많을 때 묶어 던지기를 하면 스레드가 수백 개 생길 수 있다.
- 타이머 스레드 하나가 "알릴 차례가 된 것"을 몇 초마다 DB에서 꺼내 보내는 방식으로 바꾸면 스레드가 하나로 줄고, 재시작 뒤 밀린 결과도 자동으로 보낸다.
  지금은 `_overdue`가 그 사람이 말을 걸어야 보낸다.

한 번에 다 하지 말고, 새 기능을 넣을 때 그 기능부터 새 파일에 만드는 식으로 조금씩 옮겨도 된다.

### 🟡 3-2. 명령 처리 if/elif 100여 개를 명령표로 바꾸기
```python
COMMANDS: Dict[str, Callable] = {}

def command(*names):
    def deco(fn):
        for n in names:
            COMMANDS[n] = fn
        return fn
    return deco

@command("미끼")
def _bait_cmd(link, raw, rest, payload): ...
```
- `DM_COMMANDS`와 `ROOM_REDIRECT`를 `COMMANDS.keys()`에서 자동으로 만들 수 있어서, 목록끼리 어긋날 일이 없어진다.
- `1도움말`도 각 명령의 설명을 모아서 자동으로 만들 수 있다(4-1 참고).

### 🟢 3-3. 밸런스 숫자 한곳에 모으기
- `TUG_HINT`, `LUCK`, `TREASURE`, `NET_CRAFT`, `GHOST_*`, 등급 확률이 파일 곳곳과 `config.py`에 나뉘어 있다.
- `balance.py`(또는 `balance.json`) 하나로 모으면 밸런스 패치를 할 때 한 파일만 보면 된다.

### 🟢 3-4. 확률 테스트 만들기
- `_roll`을 10만 번 돌려서 등급별 비율과 평균 포인트를 출력하는 스크립트 하나.
- 강화나 이벤트를 바꿨을 때 "하루 20만, 초대박 50만" 기준이 깨졌는지 바로 확인할 수 있다.

## 4. 처음 하는 사람 경험

### 🔴 4-1. 도움말이 너무 길다
- 지금 `1낚시도움말`은 명령이 50개 넘게 한 메시지에 나온다. 카톡에서 "전체보기"를 눌러야 하고, 처음 온 사람은 뭘 해야 할지 모른다.
- **제안**: 단계별로 나눈다.
  - `1낚시도움말` → 기본 5개만(낚시·미끼·어망·배강화·랭킹)과 "더 보기: `1낚시도움말 배` / `선원` / `바다` / `상점` / `도박`"
  - 지금 쓸 수 없는 기능(풀강 전 개조, 올 블루 전 토벌 등)은 아예 안 보여 준다.

### 🟡 4-2. 처음 낚시 퀘스트(튜토리얼)
- 연결 직후 "첫 5마리 낚기 → 미끼 확인 → 첫 강화"를 순서대로 안내하고, 하나 끝낼 때마다 미끼나 포인트를 조금 준다.
- 이미 있는 의뢰(`Quest`) 구조를 그대로 쓸 수 있다.

### 🟡 4-3. "다음에 할 일" 한 줄
- 낚시 결과 끝에 지금 상태에 맞는 한 줄을 가끔 붙인다.
  - 포인트가 다음 강화 비용을 넘었을 때 → "💡 엔진 Lv3 강화 가능 (`1배강화 엔진`)"
  - 미끼가 0일 때 → "💡 방에서 12마디 더 하면 미끼 1개"
- 강화가 핵심인 게임이라, 강화할 수 있는 순간을 알려 주는 게 가장 효과가 크다.

## 5. 강화(핵심 루프) 개선

### 🔴 5-1. 강화에 선택지 주기
- 지금은 포인트만 있으면 무조건 성공한다. 그래서 "모은다 → 누른다"뿐이라 긴장감이 없다.
- **제안 A — 안전 강화 / 도전 강화**
  - `1배강화 엔진` → 지금처럼 확정, 비용 100%
  - `1배강화 엔진 도전` → 비용 60%, 성공률 70%. 실패하면 포인트만 잃는다(레벨은 안 떨어진다).
  - 레벨이 떨어지는 실패는 넣지 않는 게 좋다. 개인톡 게임이라 화가 나면 그냥 접는다.
- **제안 B — 실패 보상(천장)**: 도전 강화를 실패할 때마다 다음 성공률 +10%. 3번 실패하면 확정.

### 🟡 5-2. 풀강 이후 목표
- 4부위 풀강 → 개조선 → 특수배 다음에 할 게 신화 상점뿐이다.
- **제안**:
  - **각성(별)**: 풀강한 부위를 비늘·정수로 ★1~★5 각성. 수치는 아주 조금만 올리고, `1배`에 보이는 모양만 바뀐다(이름 앞 아이콘, 배 카드 테두리).
  - **배 도감**: 어선·트롤선·여객선·무역선·방어선·도박선·유령선을 다 몰아 본 기록. 다 모으면 칭호.
  - 둘 다 포인트를 쓰게 만들어서 인플레이션도 같이 잡는다(6-1).

### 🟡 5-3. 강화 결과를 방에 자랑하기
- 풀강, 특수배 ★5, 신화 선원 같은 순간은 방에 한 줄로 알린다. 전설 물고기 알림(`ANNOUNCE_FROM`)과 같은 방식이다.
- 방 사람들이 "나도 해 볼까" 하게 만드는 게 개인톡 게임에서 가장 좋은 홍보다.

## 6. 경제(포인트) 밸런스

### 🔴 6-1. 포인트가 쌓이기만 하는지 확인
- 오래 한 사람은 쓸 데가 없어서 포인트가 쌓이고, 새로 온 사람과 격차가 너무 커진다.
- **확인 방법**: 상위 5명 잔액과 하루 버는 양을 1주일 정도 기록해 본다.
- **포인트 쓰는 곳 후보**(이미 있는 것과 안 겹치게):
  - 5-2의 각성, 칭호, 배 꾸미기
  - 방 전체에 영향을 주는 아이템: "30분 동안 방 전체 희귀 확률 ×1.2" — 산 사람 이름이 방에 뜬다
  - 시즌 초기화(7-1) 때 남은 포인트를 기념품으로 바꾸기

### 🟡 6-2. 약탈 피해 상한
- 약탈·검문·해왕류로 잃는 양이 하루 수익의 일정 비율(예: 30%)을 넘지 않게 한다.
- 새로 온 사람이 첫날 털리고 그만두는 걸 막는다. `보호막`이 이미 있지만, 새로 온 사람은 그게 있는지도 모른다.
  → **연결 후 3일 동안 자동 보호막**을 제안한다.

## 7. 방 활동과 이어지는 기능 (이 게임의 강점)

미끼를 방 채팅에 묶어 둔 설계가 좋다. 이 방향을 더 키우는 아이디어들이다.

### 🟡 7-1. 주간 시즌 / 방 대항
- 매주 월요일 0시에 "이번 주 낚시왕"을 정산해서 칭호와 보상을 주고 주간 랭킹을 초기화한다(통산 기록은 그대로).
- 봇이 여러 방에 있다면 **방끼리 주간 총 포인트 대결**도 할 수 있다.

### 🟡 7-2. 방 공동 목표
- "이번 주 방 전체 합계 1,000마리 → 다 같이 미끼 +5" 같은 공동 목표.
- 낚시 결과에 "방 목표 732/1000" 한 줄을 붙인다. 혼자 하는 개인톡 게임에 같이 한다는 느낌을 준다.

### 🟢 7-3. 낚시 대회 이벤트
- 운영자가 `1낚시대회 30분`을 치면, 그 시간 동안 가장 큰 물고기(cm)를 낚은 사람이 1등.
- 포인트가 아니라 **크기**로 겨루니 강화를 안 한 사람도 해 볼 만하다. `fish_record`가 이미 있어서 만들기 쉽다.

### 🟢 7-4. 오늘의 물고기
- 매일 물고기 하나를 정해 방에 공지하고, 그 물고기를 낚으면 포인트 ×2.
- 같은 날 "누가 오늘의 물고기 낚았다!"가 방에 올라오면서 대화가 생긴다.
