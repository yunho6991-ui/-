# 무협 게임 — 전투 진행 (초안)

> 뼈대 ② 전투. 무공 체계(`wuxia-martial.md`)의 숫자와 초식 문장을 써서, **카톡 메시지 한 장(6~10줄)**에 전투 하나가 끝나게 한다.
> 원칙: 강함 ≠ 안전(랜덤 사건) · 지면 무조건 죽는 게 아니다(상대의 의도) · 선택에 시간 제한 없음.

---

## 1. 한눈에

```
만남 → [전투 전 선택] → 3합 자동 진행(+ 랜덤 사건) → (위기면) [생사의 선택] → 결과 → [이긴 쪽의 선택]
```

- 보통 전투는 **선택 1번**(전투 전)으로 끝난다. 위기가 오면 1번 더.
- 선택을 기다리는 동안 다른 행동은 못 하지만 **시간 제한은 없다**.

---

## 2. 전투 전 선택

| 선택 | 판정 | 비고 |
|---|---|---|
| ⚔️ 싸운다 | 3장 | |
| 🏃 피한다 | 신법 · 지형 · 생김새(눈에 띔) | 실패하면 등을 보인 채 싸움(첫 합 불리) |
| 🗣️ 말로 푼다 | 말재주 · 호감도 · 위협(험상궂음 · 거구) | 산적 · 시비꾼 등. 혈교 · 원수에겐 안 통함 |
| 💰 돈으로 | 돈 | 산적 · 수적 · 낭인 |
| 🙇 항복 | 상대 성향 | 결과는 6장 "진 쪽" 표 그대로 |

- 특기가 있으면 선택지가 더 생긴다(독술 → "독을 탄다", 역용술 → "다른 사람인 척"). 특기 규칙과 같다.

---

## 3. 3합 — 자동 진행

- 전투는 **3합**. **먼저 2합을 이긴 쪽**이 이긴다(다대일 · 강적은 5합 · 3선승).
- 합마다 양쪽의 **기세**를 비교해 확률로 우세를 정한다.

```
기세 = 주무공 위력 × 상성 × 상태
  주무공 위력 = 무공 등급 계수 × 성취(성) × 경지 배수
  상성       = 쾌 > 중 > 유 > 쾌 이기면 ×1.3 (변은 상성 무시, 위력 ×0.8)
  상태       = 부상 · 독 · 나이 · 지형 · 기운(불 vs 마 등)
```

| 내 기세 ÷ 상대 기세 | 그 합을 이길 확률 |
|---|---|
| 2배 이상 | 90% |
| 1.3~2배 | 70% |
| 0.8~1.3배 | 50% |
| 0.5~0.8배 | 30% |
| 0.5배 미만 | 10% |

- 한 경지 차이 ≈ 기세 2배. 그래서 **한 경지 위 상대도 이길 수는 있고**(약 1/4), 두 경지 위는 거의 못 이긴다 — 랜덤 사건이 없으면.
- 메시지엔 숫자 대신 **초식 문장**이 나온다(무공 데이터의 초식 문장 3~5개 중 하나).

---

## 4. 전투 중 랜덤 사건 (철학 ②)

전투 하나에 **0~2개**. 합마다 일정 확률로 끼어든다.

| 사건 | 효과 |
|---|---|
| 무기가 부서짐 | 그 뒤 합 기세 ×0.6 |
| 암기 · 독침 | 독 상태(전투 뒤에도 남음) |
| 지형 | 비탈 · 물가 · 좁은 골목 → 신법 · 성질에 따라 ± |
| 외부 개입 | 지나가던 무인 · 요괴 · 관아 등장(유저일 수도 — W5) |
| 상대의 숨은 수 | 상대가 감춘 보조 무공 · 비기 |
| 깨달음의 순간 | 내 성취 +1성 · 벽 넘기 계기(드묾) |
| 주화입마 징조 | 무리한 쪽에 경고 |

- 사건 확률은 상대 · 장소에 따라 다르다(혈교 → 독, 당가 → 암기, 산 → 지형).

---

## 5. 생사의 선택 — 위기일 때만

내가 1합을 먼저 지고 2합째에 몰리면 한 번 뜬다.

| 선택 | 효과 · 위험 |
|---|---|
| 🔥 비기를 쓴다 | 다음 합 기세 ×2, 내공 크게 소모 · **주화입마 위험** |
| 🌀 벽을 넘는다(깨달음) | 경지 벽 앞이면 아주 낮은 확률로 그 자리에서 경지 상승 — 실패하면 주화입마 |
| 🏃 도망친다 | 신법 판정, 실패하면 중상 |
| 🙇 항복한다 | 6장 "진 쪽" 결과 |

> "목숨이 걸린 순간 벽을 넘었다"가 이 게임의 명장면이 되게.

---

## 6. 결과 — 지면 무조건 죽지 않는다

### 진 쪽에게 일어나는 일 = **이긴 쪽의 의도**
| 상대 | 주로 하는 일 |
|---|---|
| 산적 · 수적 | 약탈(돈 · 장비) 후 놓아줌, 저항이 심했으면 죽임 |
| 정파 무인 · 관아 | 제압 후 놓아줌 / 압송(악명 있으면) |
| 혈교 | **죽임 · 납치** |
| 마교 | 포섭 제안 또는 죽임 |
| 요수 | 다치게 하고 물러남 / 잡아먹음(굶주림) |
| 원수 · 현상금 사냥꾼 | 죽임 |
| 유저 | 이긴 유저가 고른다(아래) |

- 진 쪽은 상황에 따라 **경상 · 중상 · 불구**(부상 단계)를 입는다. 사망은 "상대가 죽이기로 했을 때" 또는 "중상인데 또 졌을 때".

### 이긴 쪽의 선택 (상대가 사람일 때)
| 선택 | 결과 |
|---|---|
| 살려 보낸다 | 상대 호감↑(또는 원한 유지) · 협객 소문 |
| 약탈한다 | 돈 · 일반 장비 일부 · 기연 물건 |
| 죽인다 | 그 세력 · 친구 NPC 원한, 악명(상대에 따라), **원수 기록**(전생 원한) |
| 묻는다 | 정보 · 비밀(말재주 · 위협) |
| 거둔다 | 하인 · 제자 · 동료 제안(상대 호감 · 성격) |

---

## 7. 유저끼리 싸울 때 (W2 · W5)

- **비동기**: 공격한 쪽이 행동하는 순간 전투가 끝난다. 상대 유저는 **부재 중 성향**(맞선다 · 도망 · 항복 · 돈을 준다)대로 자동 대응.
- 진 유저는 다음에 접속하면 결과를 본다: "산길에서 흑의 무인에게 당했다 — 「흑면귀」". 상대가 유저였는지는 모른다.
- 민간인(생업 꼬리표)을 공격하면 악명 · 현상금(평화로운 삶 규칙).

---

## 8. 메시지 예시

```
⚔️ 산길 — 「흑면귀」 (일류 · 녹림)
1합 ▸ 당신의 창궁무애검, 하늘을 가르는 검광이 세 갈래로 갈라진다 — 우세
2합 ▸ 놈의 개산부가 바위째 내리찍는다 — 열세
     ⚡ 놈이 소매에서 독침을 날렸다 [독]
3합 ▸ 비틀거리는 몸으로 마지막 일검 — 우세!
━━━━━━━━━━
🏆 승리 · 경상 · 독(3일)
▸ 1 살려 보낸다  2 약탈한다  3 죽인다  4 묻는다
```

- 기본 6~10줄. 숫자(기세 · 확률)는 안 보인다.

---

## 9. 정할 것

| 질문 | 메모 |
|---|---|
| 합 수 | 3합(2선승) 기본, 강적 5합 — 너무 짧거나 길지 않은지 |
| 경지 차이 = 기세 2배 | 한 경지 위를 1/4 확률로 이기는 게 적당한지 |
| 다대일 · 동행 전투 | 여럿이면 기세를 더할지, 합마다 상대를 바꿀지 |
