# 무협 게임 — 무공 체계 (초안)

> 뼈대 ① 무공. 이미 정한 것과 맞춘다: 재능 갈래(검 · 도 · 권장 · 암기 · 신법 · 내공, `wuxia-game.md` 4장) · 경지와 벽(7장) · 비급은 글 읽기 필요 · 정원 있는 기연 · 주화입마.
> 원칙: **화면엔 한 줄, 속은 깊게.** `무공 : 창궁무애검(7성·쾌) · 자하신공(4성) · 제운종(9성)`

---

## 1. 무공의 세 층

| 층 | 무엇 | 하는 일 |
|---|---|---|
| **심법**(내공) | 토납법 · 신공 | 내공을 쌓는다 → **경지**와 직결. 기운(아래 4장)을 정한다 |
| **무공**(초식) | 검법 · 도법 · 권장 · 암기 | 싸울 때 쓰는 기술. 위력 · 성질(쾌 · 중 · 유 · 변) |
| **신법**(경공) | 보법 · 경공 | 회피 · 도망 · 추격 · 잠입 |

### 몸에 지니는 칸
- **심법 1 · 주무공 1 · 보조 무공 1 · 신법 1** — 이렇게 넷만 쓴다. 배운 건 더 많아도 된다(바꿔 끼우기).
- 칸이 적어야 화면이 한 줄이고, "무엇을 들고 갈까"가 선택이 된다.

---

## 2. 무공 등급

| 등급 | 예 | 익히려면 |
|---|---|---|
| 삼류 무공 | 삼재검법 · 오행권 · 기본 토납법 | 아무나(출신 초기 무공) |
| 이류 무공 | 문파 기초 검법 · 표국검 | 문파 입문 · 스승 |
| 일류 무공 | 문파 본산 무공 | 문파 지위 · 스승 신뢰 |
| 절정 무공 | 세가 · 문파 비전 | 직계 · 심복 · 비급 |
| **신공** | 창궁무애검 · 매화검법 원본 · 천마신공 | 비급 기연 · 극소수 전수 |
| **전설** | 정원 1 기연(「천마신공」 원본 등) | 세상에 하나 — 쟁탈 대상 |

- **경지보다 두 단계 이상 높은 무공**은 못 익히거나, 익히면 주화입마 위험(5장).
- 같은 경지라도 **들고 있는 무공 등급**이 승패를 크게 가른다 → 무공을 찾아다니는 이유.

---

## 3. 성취 — 1성 ~ 12성(대성)

- 무공마다 **1~12성**. 12성 = 대성(완벽히 익힘).
- 오르는 법: **수련 행동**(꾸준히) · **실전**(빠르지만 위험) · **깨달음 사건**(한 번에 여러 성).
- 오르는 속도 = **재능**(천재 ×2 · 재능 ×1.5 · 보통 · 둔함 ×0.6, 4장).
- 위력 ≈ 무공 등급 × 성취 × 내공(경지). 낮은 등급 무공도 12성이면 무시 못 한다("삼재검법 대성한 노인").
- **전생 깨달음**(유산)은 다음 생의 시작 성취를 올려 준다.

---

## 4. 성질과 기운

### 성질 — 싸울 때 상성
```
쾌(빠름) → 중(무거움) → 유(받아넘김) → 쾌     ※ 화살표 = 이긴다
변(변칙 · 암기 · 독) : 상성을 무시하지만 위력이 낮다
```
- 상성은 승패를 정하지 않고 **기울인다**(약 ×1.3). 강함 ≠ 안전(철학 ②).

### 기운 — 심법이 정하는 몸의 성향
| 기운 | 대표 | 특징 |
|---|---|---|
| 정(正) | 무당 · 화산 · 남궁 | 안정적 · 주화입마 적음 |
| 불(佛) | 소림 | 방어 · 회복, 마 · 혈 기운에 강함 |
| 마(魔) | 마교 | 빠른 성장 · 강한 위력, 정파 호감↓(들키면) |
| 혈(血) | 혈교 | 피로 수명을 늘림 · 폭발적, 모든 세력 호감↓ |
| 요(妖) | 청구 · 요괴 | 인간이 익히면 「요기」 꼬리표 — 요괴 호감↑ · 인간 의심↑ |
| 독(毒) | 사천당가 | 독 내성 · 독공, 맹 안에서 경계 |

- **상극 기운을 섞으면**(정+마, 불+혈 등) 주화입마 위험↑. 대신 드물게 **정마합일** 같은 깨달음 사건(큰 도박).
- 기운은 생김새처럼 **다른 사람이 알아챌 수 있다**: 고수 NPC는 "마기가 느껴진다"고 반응(호감도에 영향).

---

## 5. 주화입마

| 원인 | 결과 (가벼움 → 무거움) |
|---|---|
| 벽을 억지로 넘기 | 내공 손실 → 경지 하락 → **영구 부상** → 수명↓ → 사망 |
| 상극 기운 섞기 | |
| 경지보다 높은 무공 무리하게 익히기 | |
| 마공 · 혈공 과용 | |
| 부상 중 운기 · 독 중 운기 | |

- 위험할 때는 **미리 경고 문장**이 뜬다("단전이 뜨겁게 끓어오른다…"). 멈출지 계속할지 선택.
- 아주 드물게 **전화위복**: 주화입마를 견뎌 내고 벽을 넘는다(깨달음 사건).

## 6. 무공을 얻는 길

| 길 | 조건 · 위험 |
|---|---|
| 출신 초기 무공 | 서막에서 자동 |
| 문파 입문 | 입문 시험 · 호감도. 문파 무공은 **문파 밖에서 쓰면 문제**(파문 · 추적) |
| 스승 | NPC 호감도 **신뢰** 이상 → 제자 입문 |
| 비급 | **글 읽기** 필요. 진본 · 위본(가짜 비급 → 주화입마) 섞임 |
| 기연 | 정원 있는 신공 · 전설. 주인이 죽으면 다시 강호로 |
| 훔쳐보기 | 은신 · 역용술 특기. 들키면 그 문파 원수 |
| 전투 중 깨달음 | 상대 초식을 몸으로 익힘(드묾, 천재 재능이면↑) |
| 전생 유산 | 「검술의 흔적」 → 다음 생 시작 성취↑ |
