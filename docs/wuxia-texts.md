# 무협 게임 — 5차 묶음: 문장 모음 (전투 · 깨달음 · 주화입마 · 사망 · 강호 일보)

> 코드가 꺼내 쓰는 **문장 풀**. 같은 상황도 매번 다른 문장이 나오게, 상황마다 3~6개.
> `{나}` `{상대}` `{무공}` `{초식}` `{별호}` `{지역}`은 자리 표시. 문체: 무협소설, 짧고 단단하게.

---

## 1. 합(合) 결과 문장

| 결과 | 문장 |
|---|---|
| 우세 | `{초식}이 {상대}의 빈틈을 파고든다` · `{상대}의 소매가 갈라지고 피가 번진다` · `한 걸음 빨랐다` · `{상대}가 세 걸음 물러난다` |
| 열세 | `{상대}의 {초식}이 어깨를 스친다` · `막았지만 손목이 저려 온다` · `숨이 한 박자 늦었다` · `발밑이 밀린다` |
| 팽팽 | `칼끝과 칼끝이 맞물려 불꽃이 튄다` · `둘 다 한 치도 물러서지 않는다` · `서로의 숨소리만 들린다` |
| 상성 이김 | `빠른 칼이 무거운 칼을 앞선다`(쾌>중) · `무거운 일격이 부드러운 흐름을 깨뜨린다`(중>유) · `흘려보낸 힘이 고스란히 되돌아간다`(유>쾌) |

## 2. 전투 중 랜덤 사건 문장

| 사건 | 문장 |
|---|---|
| 무기 파손 | `쨍 — 칼날 끝이 부러져 나간다` · `손안의 무기가 금이 가는 소리를 낸다` · `창대가 두 동강 난다` |
| 암기 · 독침 | `{상대}의 소매에서 무언가 번쩍인다 — 목덜미가 따끔하다 [독]` · `바람 소리 없이 날아온 바늘` · `입김에 섞인 가루가 눈을 찌른다` |
| 지형 | `발밑 자갈이 미끄러진다` · `좁은 골목, 칼을 크게 휘두를 수 없다` · `물이 무릎까지 차오른다` · `비탈 위쪽을 먼저 잡았다` |
| 외부 개입 | `지나가던 무인이 소리친다. "그만!"` · `뒤에서 낯선 칼이 끼어든다` · `호각 소리 — 관아다` · `숲에서 무언가 지켜보고 있다` |
| 숨은 수 | `{상대}의 왼손이 처음으로 움직인다 — 지금까지 숨겨 온 수` · `{상대}의 기운이 갑자기 두 배로 부푼다` |
| 깨달음의 순간 | `세상이 느려진다. {상대}의 칼이 지나갈 길이 보인다` · `몸이 먼저 움직인다 — 배운 적 없는 움직임으로` |
| 주화입마 징조 | `단전이 뜨겁게 끓어오른다` · `시야 가장자리가 붉게 물든다` · `내공이 거꾸로 흐르는 것 같다` |

## 3. 대표 무공 초식 문장 (무공마다 3~5개 — 대표만)

| 무공 | 초식 문장 |
|---|---|
| 삼재검법 | `하늘 · 땅 · 사람, 세 갈래로 찌른다` · `단순하지만 흔들림이 없다` · `수천 번 반복한 칼끝` |
| 매화검법 | `칼끝에서 매화 다섯 송이가 피어난다` · `꽃잎이 흩날리듯 검광이 흩어진다` · `향기가 먼저, 칼은 나중에` |
| 태극권 · 태극검 | `원을 그리며 힘을 흘려보낸다` · `느린 듯하나 빈틈이 없다` · `받은 힘을 그대로 돌려준다` |
| 나한권 | `주먹이 종소리처럼 울린다` · `한 걸음, 한 주먹, 산이 밀려온다` |
| 창궁무애검 | `하늘을 가르는 검광이 세 갈래로 갈라진다` · `끝없는 창공처럼 칼이 넓어진다` · `남궁의 칼은 물러서지 않는다` |
| 오호단문도 | `범 다섯 마리가 한꺼번에 덮치듯` · `칼 한 번에 문(門)이 끊긴다` · `무겁다, 그리고 빠르다` |
| 만천화우 | `하늘 가득 꽃비가 쏟아진다 — 모두 바늘이다` · `보이지 않는 곳에서 날아든다` |
| 타구봉법 | `몽둥이가 개를 쫓듯 발목을 노린다` · `휘두르는 게 아니라 얽어맨다` |
| 항룡장 | `용의 울음 같은 장풍` · `뒤로 물러서도 장력이 따라온다` |
| 천마신공 | `검은 기운이 하늘을 덮는다` · `천마가 내려다본다` · `숨이 막힌다 — 기세만으로` |
| 혈영검 · 혈수장 | `붉은 그림자가 칼보다 먼저 닿는다` · `피 냄새가 짙어진다` · `상처가 닫히지 않는다` |
| 개산부법 | `도끼가 바위째 내리찍는다` · `산을 여는 일격` |
| 여우불(요공) | `푸른 불꽃이 꼬리처럼 흔들린다` · `불인지 환영인지 모르겠다` |
| 사냥 활술 | `숨을 내쉬며 놓는다` · `화살이 바람을 가른다` |

## 4. 깨달음 · 벽을 넘을 때 (기운마다)

| 기운 | 문장 |
|---|---|
| 정 | `물이 흐르듯 막힌 곳이 뚫린다` · `칼과 내가 하나가 된다` |
| 불 | `종소리가 몸 안에서 울린다` · `분노도 두려움도 고요해진다` |
| 마 | `끓어오르던 것이 한곳으로 모인다 — 나는 더 강해졌다` · `세상이 조금 작아 보인다` |
| 혈 | `피가 노래한다` · `심장이 두 번 뛰고, 세 번째에 문이 열린다` |
| 요 | `안개 너머가 보인다` · `사람의 몸이 이렇게 좁았던가` |
| 독 | `독이 더는 독이 아니다` · `쓴맛이 단맛으로 바뀐다` |
| (공통) 경지 상승 | `🧱 벽이 무너진다 — {경지}에 올랐다` |

## 5. 주화입마

| 단계 | 문장 |
|---|---|
| 경고 | `단전이 뜨겁게 끓어오른다. 지금 멈추면 늦지 않았다…` (선택: 멈춘다 · 계속한다) |
| 가벼움 | `피를 한 모금 토한다. 며칠은 운기하지 마라` |
| 내공 손실 | `쌓아 온 내공이 새어 나간다 — 마른 우물 같다` |
| 경지 하락 | `무언가 무너지는 소리가 몸 안에서 들린다 [{경지} → {낮은 경지}]` |
| 영구 부상 | `오른팔에 감각이 없다. 다시는 돌아오지 않을 것이다` |
| 수명↓ | `거울 속 얼굴에 흰 머리가 늘었다 [최대 수명 −5]` |
| 사망 | `기혈이 뒤집힌다. 마지막으로 본 것은 거꾸로 흐르는 하늘이었다` |
| 전화위복 | `끓어오르던 것이 한순간 가라앉는다. 그리고 — 벽 너머다` |

## 6. 사망 원인 문장 (사망 정산 · 사망 원인 도감)

| 원인 | 문장 |
|---|---|
| 무공 | `「{상대}」의 {무공}` |
| 독 | `{독} — 마지막 차 한 잔` |
| 요수 | `{지역}의 {요수}` |
| 주화입마 | `거꾸로 흐른 내공` |
| 수명 | `천수(天壽)` |
| 사고 | `산사태` · `폭풍` · `얼음 구멍` · `독안개` |
| 배신 | `믿었던 「{이름}」` |
| 처형 | `무림맹의 법` |
| 희귀(도감 자랑용) | `독버섯 한 접시` · `술 내기` · `웃음이 멈추지 않는 독` · `사부의 장작 패기(?)` |

## 7. 강호 일보 문장 틀

| 종류 | 틀 |
|---|---|
| 큰 사건 | `📜 {사건}. 강호가 술렁인다.` (예: 맹주가 쓰러졌다) |
| 별호 활약 | `· 「{별호}」가 {지역}에서 {행적}` |
| 기연 소문 | `· 누군가 「{기연}」을 손에 넣었다는 소문이 돈다` |
| 고정 출신 | `· {출신 소문}` (예: 혈교가 또 아이들을 데려갔다 — 남은 자리 2) |
| 사망 | `· 「{별호}」가 {지역}에서 쓰러졌다 — {사망 원인}` |
| 혼인 | `· 「{히로인/인연}」이 누군가와 혼인했다` |
| 시작 | `📜 천기가 흔들렸다. 강호의 시간이 하나로 묶인다.` |
| 회귀 | `📜 하늘이 접힌다. 모든 것이 처음으로 돌아간다. …그러나 누군가는 기억한다.` |
