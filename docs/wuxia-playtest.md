# 무협 게임 — 출시 전 플레이테스트 체크리스트

> 기획서 12장(완성 후 공개 · 내부 플레이테스트)을 **실제로 확인할 항목**으로 만든 것. 로드맵(`wuxia-roadmap.md`) 단계마다 해당 부분을 돌린다.
> 원칙: **개발자가 아는 정답대로 하지 않는다.** 일부러 이상하게, 대충, 악하게 해 본다.
> 표시: `- [ ]` 확인할 것 · 🔴 출시를 막는 문제 · 🟡 고치면 좋은 것.

## 1. 단계별 체크

### M0~M5 — 작은 강호 한 판(CLI)
- [ ] `python3 tools/wuxia_data_check.py`가 작은 강호 범위에서 빠진 id 0개
- [ ] `1강호` → 빙의 화면이 12줄 안에 나온다(출신 · 성별 · 생김새 · 재능 · 특기 · 일지)
- [ ] 농부 서막 1~3단계가 ★ 사건 + 랜덤 사건으로 진행된다(두 번 해서 **다른 사건**이 나오는지)
- [ ] 산적 습격(2단계)이 3합 전투로 끝나고 이기면 · 지면 결과가 다르다
- [ ] 노석이 살거나 죽는다 — 죽으면 곰칼이 물러나는 문장이 나온다
- [ ] 결말 선택지가 **조건대로만** 보인다(노석 신뢰 없으면 "노석께 간다" 안 보임)
- [ ] 서막 뒤 청하진에서 행동 메뉴(수련 · 탐험 · 의뢰 · 생업 · 이동 · 치료)가 돈다
- [ ] 특기 · 생김새로 열린 선택지에 **(이유)**가 붙는다
- [ ] 행동력이 줄고 1시간에 1씩 찬다(최대 20) — `--fast`가 아니면
- [ ] 나이가 행동 1번 = 10일씩 먹는다
- [ ] 죽으면 사망 정산 → 유산 후보 3개 중 1개 → 새 빙의로 이어진다
- [ ] 행동 36번 미만에 죽으면 "짧은 생" 화면 · 유산 거의 없음
- [ ] 같은 씨앗(`--seed`)으로 두 번 돌리면 **똑같이** 나온다(버그 재현용)
- [ ] 🔴 한 생을 처음부터 사망까지 **재미있게** 끝까지 해 봤다(아니면 콘텐츠 늘리기 전에 고친다)

### M6 — 카톡 연결
- [ ] 개인톡에서 `1강호` · `1행동 n`이 CLI와 같은 화면
- [ ] `연결` 안 한 개인톡에선 안내 문장만
- [ ] 답장이 12줄 · 400자 안팎 — "전체보기"로 접히지 않는다(사망 정산 · 일지만 예외)
- [ ] 🔴 같은 사람이 `1행동`을 빠르게 두 번 보내도 행동력 · 결과가 두 번 처리되지 않는다(사람별 잠금)
- [ ] 선택 대기 중에 몇 시간 뒤 답해도 그대로 이어진다(시간 제한 없음)
- [ ] 선택 대기 중 `1행동`(번호 없이)을 치면 기다리는 선택을 다시 보여 준다
- [ ] 봇 재시작 뒤에도 대기 선택 · 행동력이 남아 있다
- [ ] 낚시 명령이 그대로 잘 된다(무협이 낚시를 건드리지 않음)
- [ ] `강호` · `행동`이 다른 명령과 겹치지 않는다

### M7 — 세계
- [ ] 하루가 지나고 처음 말을 걸면 세계 배치가 **한 번만** 돈다(두 사람이 동시에 걸어도)
- [ ] NPC가 하루 행동을 한다(전보가 아이를 보냄 → 의식 진행도 오름)
- [ ] 호감도 숫자가 **어디에도 안 보인다** — 반응 문장으로만
- [ ] 강호 일보가 하루 한 번, 소식 받는 방 전부에 같은 내용으로
- [ ] 방별 "섞임 끄기"가 동작한다(W6)

### M8~M9 — 출신 · 장소 · 고정 출신
- [ ] 출신 13개 + 도시 출신 5개 모두 빙의 → 서막 → 결말까지 간다
- [ ] 흔한 출신이 고을 8 · 도시 6에 **흩어진다**(한 곳에 몰리지 않음 — 100번 굴려 분포 보기)
- [ ] 고정 출신 정원이 세계 전체 기준으로 줄어든다 · 죽어도 안 돌아온다
- [ ] 한 사람이 같은 고정 출신을 한 시즌에 두 번 못 받는다
- [ ] 공유 서막(혈교 · 남궁)이 **실제 날짜**로 단계가 넘어간다(메인 전에도)
- [ ] 늦게 들어오면 살아 있는 NPC에 빙의 + 그 NPC의 **일지**가 보인다
- [ ] 직전 생이 짧았으면 고정 출신 확률이 낮다

### M10 — 메인
- [ ] 메인 전엔 강호 날짜가 멈춰 있고, 시작 단서 셋을 모으면 「천기가 흔들린 날」
- [ ] 아무도 못 터뜨리면 n일 뒤 저절로 시작
- [ ] 시작 사건 종류에 따라 1막 첫 흐름이 다르다
- [ ] 세계 변수대로 막이 넘어간다(의식 · 맹주 수명 · 결속 …)
- [ ] 메인 사건이 전체 사건의 약 15% — 그 지역 · 꼬리표가 없으면 소문으로만
- [ ] 4막: 예선은 출신 무관 · 원로회 추대 / 민심 추대 둘 다 열린다
- [ ] 유저가 맹주가 될 수 있다 — 세율을 정할 수 있다(범위 안에서)
- [ ] 7막 결말 넷(저지 · 연합 · 청구 봉인 · 강림)이 모두 나올 수 있다
- [ ] 회귀: 캐릭터 · 유산 · 기록 전부 비고, 넘어가는 변수 1~3개만 남는다

### M11 — 유저끼리
- [ ] 🔴 **정체가 새지 않는다**(아래 3장 전부)
- [ ] 공격하면 상대는 부재 중 성향대로 대응 · 결과는 상대가 다음에 말을 걸 때 보인다
- [ ] 약탈 범위: 돈 · 일반 장비 일부 · 기연 물건만(유산 · 기억은 못 뺏음)
- [ ] 민간인(생업 꼬리표)을 해치면 악명 · 현상금
- [ ] 혼인은 세계에 한 번 — 두 사람이 같은 인연을 연모하다 한 명이 혼인하면 다른 사람에겐 소식만

## 2. 테스터 성향별 (기획서 12장)

| ✔ | 하는 법 | 볼 것 |
|---|---|---|
| [ ] | **아무 정보 없이**: 문서를 안 본 사람에게 `1강호`만 알려 줌 | 10분 안에 뭘 할지 아는가 · 처음 막힌 곳 |
| [ ] | **랜덤 행동**: 번호를 무작위로만 | 그래도 이야기가 되는가 · 같은 사건 반복 |
| [ ] | **극단적 행동**: 모든 걸 죽이고 약탈 | 악명 · 현상금 · 세력 적대가 따라오는가 |
| [ ] | **트롤**: 선택 대기에서 이상한 입력 · 아주 큰 번호 · 빈 입력 · 명령 연타 | 🔴 오류 · 멈춤 · 두 번 처리 없음 |
| [ ] | **빠른 성장**: 수련 · 강적만 | 주화입마 · 사망 위험이 제대로 막는가 |
| [ ] | **빠른 사망(리롤)**: 일부러 빨리 죽기 반복 | 🔴 짧은 생 벌칙이 리롤을 손해로 만드는가 |
| [ ] | **무공 하나만** | 상성 · 성질 때문에 막히는 순간이 있는가 |
| [ ] | **세력 하나만** | 소속 사건이 계속 새로운가 |
| [ ] | **돈만** | 🔴 돈이 끝없이 불어나는 고리 없음(생업 · 장사 · 도박 · 되팔기) |
| [ ] | **전투만** | 싸움 빈도 · 사망률이 모의실험과 비슷한가 |
| [ ] | **평화롭게만** | 천수까지 지루하지 않은가 · 메인에 휘말리는가 |
| [ ] | **인연만** | 13+13 인연이 각자 다르게 느껴지는가 |

## 3. 정체가 새는 곳 (W5) — 🔴 전부 확인

- [ ] 어떤 화면에도 카톡 닉네임 · 방 이름이 안 나온다
- [ ] 유저 캐릭터와 NPC의 표시 형식이 **완전히 같다**(`「이름」 (경지 · 세력)`)
- [ ] 응답 속도 · 타이밍으로 티가 안 난다(유저끼리 만남도 내 행동 때 처리)
- [ ] 강호 일보 · 사망 정산 · 사망 원인에 "유저" 표시 없음
- [ ] 다시 태어난 원수에게 아무 힌트 없음(NPC 원수만 알아봄)
- [ ] 공유 서막 무리 안에서 누가 유저인지 알 수 없다
- [ ] 랭킹 · 기록에서 별호만 보이고 계정과 이어지지 않는다

## 5. 문장 · 표현

- [ ] 같은 상황 문장이 반복돼도 지겹지 않다(문장 풀 3~6개)
- [ ] 오탈자 · 자리 표시(`{상대}`) 그대로 나오는 곳 없음
- [ ] 🔴 미성년 인물(혈교 아이 · 동자승 · 남궁린 등)에 대한 폭력은 **암시만**, 성적인 묘사 없음
- [ ] 🔴 연모 · 요염 묘사는 성인만, 품위 있게
- [ ] 잔혹 · 유혈 묘사가 과하지 않다(무협소설 수준)
- [ ] 컴피 그림이 문장과 맞는다(초상 · 장소)

## 6. 운영 · 안전

- [ ] 데이터 오류가 나면 무협 모듈만 꺼지고 봇 전체는 산다
- [ ] 시즌 중 YAML만 고쳐서 재시작하면 반영된다(코드 수정 없이)
- [ ] DB 백업 · 복구가 된다(시즌 도중 사고 대비)
- [ ] 강호 일보 보내기가 낚시 메시지 줄을 막지 않는다
- [ ] ⚠️ 현금 결제 · 현금화 경로가 어디에도 없다
