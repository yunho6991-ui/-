# 무협 게임 — 만날 수 있는 남성 인연 캐릭터

> `wuxia-heroines.md`와 같은 틀 · 같은 인연 규칙(만남 → 관심 → 신뢰 → 연모 → 혼인, 연모는 개인별 · 혼인은 세계에 한 번, 죽을 수 있음, 회귀해도 나는 기억함).
> 모두 **성인**. 잘생김 · 귀여움 · 거친 매력 · 반전 매력이 겹치지 않게. 빙의한 인물의 **성별은 랜덤**이고, **인연은 성별과 상관없이** 열린다(`wuxia-game.md` 4장).
