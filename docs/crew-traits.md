# 선원 개성 — 같은 역할·등급이라도 조금씩 다르게

> 지금은 역할 + 등급만으로 능력이 정해진다(`Mate.value`). 같은 등급 전설 둘, 같은 역할 신화 10명은 능력이 완전히 같다.
> 이 문서는 선원마다 **개성 하나**를 붙여 차이를 주는 안이다. 코드는 고치지 않았다.

---

## ⭐ 단순화 버전 (추천)

**규칙 한 줄: "조건이 맞으면 그 선원의 능력이 조금 더 세진다."**

- 주 능력(요리사 = 채팅 미끼, 행운펫 = 희귀 ×, …)은 **그대로**. 신화 고유 능력(`MYTH_POWER`)도 그대로.
- 선원마다 **개성 하나**가 붙는다. 개성은 아래 **두 가지 종류뿐**이다(시간 · 날씨).
- **올라가기만 하고 내려가지 않는다.** 조건이 안 맞아도 지금과 똑같다. 그래서 몰라도 손해가 없다.
- 새 명령 없음. `1선원`과 선원 카드에 **한 줄**이 늘 뿐이다. 낚시 결과 메시지에는 아무것도 안 붙인다.

### 개성 종류 (세 가지)

| 종류 | 조건 | 세지는 정도 | 카드에 보이는 한 줄 (예) |
|---|---|---|---|
| ⏰ **시간형** | 새벽(0~6시) / 아침(6~12시) / 저녁(18~24시) | 새벽 ×1.5 · 아침 ×1.3 · 저녁 ×1.3 | `🌙 새벽형 · 0~6시에 능력 ×1.5` |
| 🌦️ **날씨형** | 맑음 / 비 / 안개 / 폭풍 / 보름달 (방의 오늘 날씨) | 맑음 ×1.2 · 비 ×1.4 · 안개 ×1.5 · 폭풍 ×1.5 · 보름달 ×1.6 | `🌧️ 비를 좋아함 · 비 오는 날 능력 ×1.4` |

- 날씨 배수는 **자주 오는 날씨일수록 작게** 잡았다. 맑음(40%)×1.2, 보름달(10%)×1.6 → 어느 날씨형을 골라도 평균 이득이 비슷하다(평균 +6~9%).
- 전체적으로 선원이 평균 5~10% 세진다. 너무 세다 싶으면 **배수만** 낮추면 된다.

> **해역형은 넣지 않는다.** 올 블루 개성은 끝판 유저에게 사실상 늘 켜진 보너스가 되고, 이스트 블루 개성은 그 유저에게 영영 안 켜진다. 같은 "개성 하나"인데 사람마다 가치가 너무 달라진다.
> 시간형은 "내가 주로 언제 하느냐"에 맞춰 고르는 재미가 있고, 날씨형은 방마다 매일 무작위라 모두에게 공평하다.

### "능력 ×1.5"가 실제로 뜻하는 것

능력의 **덤 부분**에만 곱한다(기본값까지 커지지 않게).

| 역할 | 지금 값의 뜻 | 개성 적용 |
|---|---|---|
| 요리사 | 채팅 n마디마다 미끼 1개 (기본 30) | 줄어드는 마디만 커짐. 예: 20마디(−10) ×1.5 → 15마디(−15) |
| 행운펫 | 희귀 이상 ×v | `1 + (v−1) × 배수`. 예: ×1.2 → ×1.3 |
| 해적 | 보물·전리품 +v (시즌 2 재설계, 맨 아래) | `v × 배수` |
| 목수 | 배 강화 비용 −v (시즌 2 재설계, 맨 아래) | `v × 배수` (할인 상한 15%) |
| 비서 | 낚은 포인트 +v | `v × 배수` |
| 낚시꾼 | 미끼 하나마다 v 확률로 안 줄어듦 | `v × 배수` |

> 덧붙이는 확률(해적 NPC 기습 성공률 +, 목수 파손·수리비)과 신화 고유 능력은 건드리지 않는다. 손댈 곳을 `value` 하나로 줄이기 위해서다.

### 피한 조합
- **해적·목수**에게는 **안개**(배가 안 보여 싸움이 없음) 개성을 주지 않았다. (시즌 2 재설계 후에는 두 역할 모두 싸움과 상관없는 능력이라 이 제한은 없어도 된다. 그대로 둬도 문제없음.)

## 코드에 넣을 때 (나중에 로컬에서)

손댈 곳이 적게 설계했다. **표 하나 + 함수 하나**, 그리고 `value`를 읽는 곳 몇 군데를 그 함수로 바꾸면 된다.

```python
# 개성: 선원 id → (종류, 조건). 종류 = "time" | "weather"
TRAIT: Dict[str, Tuple[str, str]] = {
    "cook_c": ("time", "아침"), "cook_u": ("time", "저녁"), "cook_r": ("weather", "비"), ...
}
TRAIT_MULT = {"새벽": 1.5, "아침": 1.3, "저녁": 1.3,
              "맑음": 1.2, "비": 1.4, "안개": 1.5, "폭풍": 1.5, "보름달": 1.6}

def trait_mult(m: Mate, chat_id: str, key: str) -> float:
    """지금 이 선원의 개성이 맞으면 배수, 아니면 1.0."""
    t = TRAIT.get(m.id)
    if t is None:
        return 1.0
    kind, cond = t
    if kind == "time":
        h = datetime.datetime.now().hour
        on = {"새벽": h < 6, "아침": 6 <= h < 12, "저녁": h >= 18}[cond]
        return TRAIT_MULT[cond] if on else 1.0
    return TRAIT_MULT[cond] if weather(chat_id, key=key).name == cond else 1.0
```

- `value`를 읽는 곳(`_mate_of` 뒤의 행운펫·요리사·비서·낚시꾼 계산, `_angler_save` 등)에서 위 "개성 적용" 표대로 덤 부분에만 곱한다.
- 카드·`1선원`에 한 줄: `_mate_effect` 끝에 개성 설명 한 줄. 조건이 지금 맞으면 끝에 `(지금 발동 ✨)`.
- 일괄낚시처럼 한 번에 많이 계산하는 곳은 시작할 때 `trait_mult`를 한 번만 계산해 둔다.

## 풀 버전 (참고용 — 추천하지 않음)

더 다양하게 하고 싶을 때 쓸 수 있는 것들. 1순위 기준에 걸려서 기본으로는 넣지 않는다.

| 아이디어 | 왜 빼는가 |
|---|---|
| **해역형** — 특정 해역에서 ×1.3 | 끝판 유저에겐 올 블루 개성이 늘 켜지고 이스트 블루 개성은 영영 안 켜진다. 가치가 사람마다 너무 다르다 |
| **양날 개성** — 조건이 맞으면 ×1.5, 안 맞으면 ×0.85 (평균은 같게) | 몰라도 손해 보는 구조가 된다(기준 5) |
| **기분파** — 매일 무작위로 ×0.7~×1.4, `1선원`에 오늘 컨디션 표시 | 새 개념(컨디션)이 하나 생긴다 |
| **고유 스킬** — 선원마다 완전히 다른 능력 하나씩(96개) | 외울 게 96개. 밸런스 맞추기도 어렵다 |
| **선원끼리 궁합** — 특정 두 선원을 같이 태우면 보너스 | 조합을 찾아봐야 해서 복잡하다(backlog I-03) |
| **개성 바꾸기** — 비늘로 개성을 다시 뽑기 | 새 소비처·새 명령이 생긴다 |
| **개성 두 개** — 시간 + 날씨 둘 다 맞으면 더 큰 보너스 | 한 줄 설명이 안 된다 |

## 시즌 2: 해적 · 목수 선원 재설계

> 유저 간 약탈이 NPC 상대로 바뀌면서(`pvp-rework.md`), 약탈용으로 만든 두 역할이 약해진다.
> - **해적**: "유저를 털 때 더 가져옴"이 NPC 상선을 만날 때만 쓰인다 → 쓸 일이 드물다.
> - **목수**: "덜 털림"이 통째로 사라지고 파손·수리만 남는다 → 6역할 중 가장 약해진다.
>
> 두 역할을 **혼자 플레이에서 늘 쓰이는 능력**으로 바꾼다. 수치(`value`)는 그대로 두고 **뜻만** 바꾼다(숫자 하나 바꾸기 원칙).

### 단순화 버전 (추천)

| 역할 | 지금 | 바뀐 뒤 (한 줄) | 늘 쓰이나 |
|---|---|---|---|
| 🏴‍☠️ 해적 | 유저 기습 성공률 +, 이기면 v 더 가져옴 | **보물 사냥꾼**: 모든 보물·전리품 +v (해적의 보물상자 물고기, 유령선 보물, NPC 상선 전리품, NPC 해적 승리 보상) | ✅ 보물상자는 평소 낚시에도 나온다 |
| 🔨 목수 | 유저에게 덜 털림, 상대 기습 −, 파손 ↓, 수리비 ↓ | **배 장인**: 배 강화 비용 −v (+ 파손 ↓·수리비 ↓는 그대로) | ✅ 강화는 누구나 계속 한다 |

**목수 할인 크기** — 강화가 시즌 2의 주 소각처라서(`season2-plan.md` 경제) 할인은 작게 잡는다.

| 등급 | 일반 | 고급 | 희귀 | 영웅 | 전설 | 신화 |
|---|---|---|---|---|---|---|
| 강화 할인 | 2% | 3% | 5% | 7% | 10% | 12% |

> 지금 목수 `value`(0.05~0.3)를 그대로 할인으로 쓰면 최대 30%라 너무 크다. 위 표처럼 따로 잡거나 `value × 0.4` 정도로.
> 개성 배수가 붙어도 할인은 **최대 15%**에서 자른다.

**해적 보물 크기** — 지금 해적 `value`(0.05~0.3)를 그대로 "+5%~+30%"로 쓴다. 보물은 원래 드물어서 커도 경제 영향이 작다.

### 신화 고유 능력

| 역할 | 지금 | 바뀐 뒤 |
|---|---|---|
| 해적 | 🌌 토벌 작살 피해 × | **그대로** (해왕류 토벌은 원래 NPC 상대) |
| 목수 | 🌌 요새: 뺏기는 양 ×, 기습 실패자 배상 × | 🌌 **명장의 손**: 강화할 때 10% 확률로 비용을 받지 않는다 |

### 같이 바뀌는 것
- 갑판 이벤트(해적 = 보물선 추격, 목수 = 그물 제작)는 원래 혼자 플레이라 **그대로**.
- 유령 선원 해적 효과(`GHOST_PIRATE_LOOT`, 보물 +)는 새 해적 능력과 같은 방향이라 **그대로**.
- 유령 선원 목수 효과(`GHOST_CARPENTER_KEEP`, 잡혀도 일부 건짐)는 유령선 안 이야기라 **그대로**.
- 선원 카드 설명(`_mate_effect`)의 해적·목수 문구만 바꾼다.
